# ウサギ・イヤ・ラビット (Rabbiters)

ウサギになって食料を探し、捕食者から隠れながら旅をし、森で四つの季節を生きのび、生まれた子ウサギを新しい野原へ導く協力ステルスサバイバルゲームの試作です。ホストがゲームを計算し、MoQ Relayは入力と状態を中継します。ホストがいなくなった場合の引き継ぎはありません。

## 起動

Node.js 24とnpmを用意し、リポジトリ直下で実行します。初回は既存ゲーム用SDKのセットアップと、Rabbiters用`moq-wasm`のリリースtarballを含む依存関係のインストールが必要です。

```sh
node scripts/setup-sdk.mjs
npm ci --ignore-scripts
npm run dev:rabbiters
```

`http://127.0.0.1:5193/`を開きます。ソロならRelayは不要です。協力プレイでは「みんなではじめる」から参加者が同じルーム名を入力し、一人が「ルームを作る」、残りが「ルームに参加」を選びます。Relayは`https://relay.moqt.research.skyway.io`で、画面には表示しません。別のRelayを使う場合はURLに`?relayUrl=https://...`を付けます。RelayはMoQのnamespace watch・announce・publish・subscribeをサポートし、`anon/rabbiters-v1/<room>`を使用できる必要があります。WebTransportを使えるブラウザと、ブラウザが信頼するRelayのTLS証明書が必要です。ルーム名やプレイヤーIDは認証ではないため、信頼できるRelayと参加者で利用してください。

別の端末から参加する場合は、ゲーム自体も各端末からアクセスできるHTTPSの配信先に配置してください。`127.0.0.1`は開いている端末自身を指します。

更新前のホストからは、食べものの種類や新しいステルス情報がない状態も受け取れます。新しいホストは、旧参加者にも読める捕食者の状態と、新参加者向けの詳細状態を送ります。古いページでは捕食者の疑い表示が省略される場合があるため、全員がページを再読み込みすると最新の表示で遊べます。ただしマップ拡張（288×200 m）より前のホスト・参加者とは地形と食べものの配置が異なるため、同じルームでは遊べません（参加者側は状態を受け取らず待機します）。

PCはWASD／矢印で移動、Spaceでジャンプ、Shiftでダッシュ、Cでしゃがむ（砂地で長押しすると砂浴び。モグラの穴の上ではCで地下へもぐり、出口の下でSpaceを押すと地上へ出ます）、E長押しで巣の破壊または仲間の救助、フィールドをクリックするとマウスカーソルが固定され（Pointer Lock）、ボタンを押さずにマウスを動かすだけでTPS視点が回転します。Escで解除でき、Pointer Lockが使えない場合は従来どおりドラッグで回転します。タッチ操作は画面のスティックとボタンを使い、フィールドのドラッグで視点を回転できます。画面上部の♪ボタンでBGMと効果音を切り替えられます。

食べものに近づくと自動で食べます。草むら・茂み・倒木の下・浅瀬でしゃがむ、洞窟や木のうろ・巣穴・モグラのトンネルに入る、丘や窪地の陰に回るなどして敵から隠れられます（詳しくは下の「マップとステルス」）。巣の卵を壊すと敵の追加出現が減り、すべて壊すと止まります。

## ものがたり（4章）

ペットのウサギ「モチ」がケージを抜け出し、町と水の道をこえて森にたどり着くまでの4章構成です（設計とエンジンの仕様は [STORY.md](STORY.md)）。

| 章    | タイトル     | 舞台                                       |
| ----- | ------------ | ------------------------------------------ |
| 第1章 | ケージの外へ | 家と庭                                     |
| 第2章 | 知らない町   | 町（路地・大通り・商店街・神社・夜の土手） |
| 第3章 | 水の道       | 下水道（夜）→川（夜明け）→公園（朝）       |
| 第4章 | 森へ         | 森（下の四季キャンペーン）                 |

第1・2章は今のところ、部屋や通りに出口が一つあるだけの仮のステージです。新しく始めると第1章から。章の目標は左下の目標カードと画面の目印（光る輪とひし形）で示され、NPCのそばでEを押すと話せます。会話は画面上部の字幕と頭上の吹き出しで流れ、ゲームは止まりません。人間に捕まるとチェックポイントへ戻され、車にひかれると倒れます。到達した章はブラウザに記録され、タイトルの「はじめる章」から続きを選べます（`?chapter=1`〜`4` でその章を選んだ状態で開きます）。

### 第3章「水の道」：下水道・川・公園

264×132の一つの地図を西から東へ進み、区域に合わせて夜→夜明け→朝になります（目標は11、全員で共有）。

- **下水道**（暗い：見つかりにくさ×0.6、月明かりの格子は×1.3）：中央の深い水路は泳げず、歩廊・橋・横断する土管（しゃがんで入り、ジャンプで出る）で行き来します。ヒキガエルのガマ先生と話し、ネズミの巣のガラクタをあさって（E長押し）バルブのハンドルを取りもどし、北の水門と作業員の部屋のバルブを回し（各55秒、2羽なら半分、3秒ごとに音が出る）、水が引くのを待って（65秒）排水口へ。作業員の懐中電灯の前は×2.2で見つかりやすく、3匹のネズミはにおいをたどって噛みつきます（傷は浅い）。
- **川**（夜明け）：葦に隠れ、釣り人（見つけると大声で周りを呼ぶ）とカラスの目を盗んで、飛び石と中州で急流を渡ります。水に足をつけるか、ときどき来る増水（45秒ごとに14秒）の間に石に立っていると流されて排水口に戻ります。橋の下は野良犬3匹のねぐら。犬たちが南のゴミ置き場へ出かけたすきに抜け、土手の下の暗渠から公園へ。
- **公園**（朝）：犬の散歩、ジョギングの人、遊び場の子ども2人、管理人さん。ベンチの下・植え込み・トンネル遊具に隠れられます。池のカメ・ゲンじいに花だんのタンポポを4つ届けると、裏山の先の森のことを教えてくれます。裏のフェンスの網をかじって（60秒）穴を抜けると第4章へ（1羽が抜ければ全員で進みます）。

捕まったウサギは、その区域の人が入れない場所（入口の土管、排水口の中、暗渠、ベンチの下）に戻されます。所要時間の目安（ユニットテストのボット）：脅威なしの最短で約8.4分、慎重なボットで敵ありの場合23〜30分。

### 第2章「知らない町」

家の庭を抜けたモチが、夕方の町を東へ進み、夜の土手の下の下水道に入るまで（320×160 m、`src/stages/town/`）。目標は6つで、目標カード・ヒント・画面の目印が次にやることを示します。

1. **路地を抜ける**：ブロック塀の路地。野良猫のボス「トラ」と子分2匹がそれぞれの路地を見回ります（速く、噛む）。段ボールやバケツのそばでしゃがめば見つかりません。
2. **ポン太を手伝う**：ゴミ置き場のタヌキのポン太と話し、カラスよけネットをE長押し（30秒）でかじる（音でカラスやネコが来る。ネットのふたの下なら空から見えない）。キャベツを南の路地のおくの子ダヌキへ運び（くわえると遅く目立つ）、戻ると半分分けてくれて、排水管の近道を教わります。
3. **大通りを渡る**：片側1車線ずつ、車は数台ずつの列ですき間が読めます。ひかれると倒れます。停めてある車の下はしゃがんで隠れられ、歩道の格子ぶたからCで排水管にもぐって向こうの歩道に出られます（出口でSPACE）。歩道には通行人。
4. **商店街を抜ける**：両側の店先の陳列台の下は人から見えません（すき間で見つかりやすい）。真ん中に花のプランター。ペットショップのハムスター「くるみ」が神社のハトのことを教えてくれます。買い物客と、見つけると走ってくる子どもたち。
5. **神社でポッポと話す**：裏通り（車）を渡って鳥居へ。ハトのポッポはおなかがすいて思い出せないので、パン屋の店先のパンのみみを運びます。東の川の方角を聞いたら、社の床下（だれも入れない避難所・チェックポイント）で日が暮れるのを待ちます。神主さんが見回って帰ります。
6. **土手の下の入口へ**：夜。買い物客は帰り、川沿いを犬の散歩（人＋リードの犬。犬はフンのにおいをたどり、吠えると飼い主が来る）。街灯の下は見つかりやすく（×1.3）、暗がりは見つかりにくい（×0.6）。土手の上の道には車のヘッドライト。下水道の入口のさびた格子をE長押し（30秒、ガチャガチャ鳴る）でこじ開けて入るとクリア。

人間（通行人・買い物客・子ども・神主・散歩の人）は自分の歩道・通り・境内から出ず、路地の奥までは追ってきません。捕まるとその目標のチェックポイントへ戻されます。協力プレイでは目標・会話・運ぶもの・格子の進み具合は全員で共有し、だれか1羽が入口に入れば全員で次の章へ進みます（倒れている仲間もいっしょ）。食べものは路地の草、陳列台の下に落ちた野菜、境内の草とお供えのリンゴ、土手のクローバーなど31か所。

### 第1章「ケージの外へ」：家と庭

ひなたの家（リビング・ダイニング・台所・洗面所・廊下・玄関・お風呂・和室・書斎）と裏庭の約30分のステルス章です。壁は高さ7で天井はなく、家具の下（ソファ・ローテーブル・食卓と椅子・靴箱・ちゃぶ台・机・縁側・物置）はしゃがむ／そのまま入れる隠れ場所で、人間は入れません。カーテン・観葉植物・洗濯かご・生け垣は茂み、庭の畑と花壇は草むらです。ケージの中は「おうち」で、だれにも気にされません。庭の日なたとリビングの窓ぎわは見つかりやすく、廊下と奥の部屋は薄暗くて見つかりにくくなっています。

1. **目を覚ます**：ケージのペレットを3つ食べ、となりのピーすけと話す（Eで会話）。会話が終わると母の声かけに続いてひなたが学校へ出かける。時間帯が変わるまで待つ必要はありません。
2. **留め金をかじる**：扉のそばでEを長押し（合計30秒、途中でやめても残る）。カチカチという音は近くの人に聞こえ、見に来た人がそばにいると留め金を少し戻されます。昼にお母さんがリビングで洗濯物をたたむので、すきを見て。
3. **タマに会う**：和室の座布団の老猫タマと話す。
4. **煮干しを3匹運ぶ**：台所の低い棚の下でEを長押しして袋から煮干しを引っぱり出し（ガサガサ音は流し台のお母さんにも聞こえます）、くわえてタマへ。冷蔵庫の裏のネズミ穴は押し入れへの近道（穴のそばでC、出口でSPACE）。
5. **首輪のタグを探す**：ひなたが帰ってきて「モチがいない！」と家じゅうを探し始めます。玄関の土間（一段低い。上がるときはジャンプ）の靴箱の下からタグを取り、洗面所の猫ドアの前でEを長押し。
6. **庭を抜ける**：庭の真ん中には鎖につながれた番犬ゴン（鎖の長さ7）。見つかると吠えて、お母さんが勝手口から見に来ます。フェンスの下のすき間をEの長押しでほって広げ（15秒、音が出る）、しゃがんでくぐると第2章へ。協力プレイでは、倒れていない全員がフェンスの外にそろうと次の章へ進みます（倒れた仲間はそのまま連れていきます）。

家族は朝→昼→午後（各200秒）をくり返します。朝は全員が家に（お父さんは食卓で新聞）、昼はお父さんが外出し、お母さんは台所・洗面所・リビングを回り、午後はお父さんが帰宅してお母さんは庭で洗濯物を干します。脱走がばれると「モチ探し」になり、家族は部屋を見回って「モチー？」と呼びます。人間に捕まるとケージに戻され、くわえていたものは元の場所に戻ります（扉は閉まりますが、留め金はこわれたままなのでEの長押しですぐ押しあけられます）。脱走したあとは、ピーすけのそばでEを押すと「ピンポーン！」と騒いで近くの人をリビングに呼び寄せます（45秒に一度）。

### 第4章「森へ」：四つの季節

四つの季節をめぐる約30分のキャンペーンです。到着すると長老ウサギのヨモギ（巣穴のそば、Eで助言）が迎えます。成長と妊娠の時間だけで最短でも約17分かかり、敵から隠れ、食べものを探しながら進めると30分前後になります。

| 章             | 目標                                                                                                                                                                                                                                                            |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 春「芽吹き」   | 食べものに近づくと自動で食べます。6回以上食べ、約5分たつと大人になります。                                                                                                                                                                                      |
| 夏「巣づくり」 | 野原に散らばった巣材6束を、1束ずつ巣穴まで運びます。くわえている間は遅くダッシュできず、敵に見つかる距離が1.3倍になり、攻撃されると巣材を元の場所に落とします。                                                                                                 |
| 秋「みのり」   | 巣が整うと、大人でおなかが50以上のウサギが妊娠します（一度に一羽）。約10分生きのびると出産します。妊娠中は移動が遅く、空腹が早く進み、空腹が尽きると出産も進みません。                                                                                          |
| 冬「旅立ち」   | 生まれた3羽の子ウサギは、7m以内にいる一番近いウサギについてきますが、歩くより遅く走りには追いつけません。小川を浅瀬で渡り、大樫のうろ（木の根元の隠れ場所）まで導くとクリアです。敵に捕まった子ウサギは連れ去られ、捕まえた敵は去ります。全員を失うと失敗です。 |

子ウサギは、隠れ場所の中で導いているウサギがしゃがむと一緒に隠れます。5分ごとに夜（約100秒）が来て、タカは眠るかわりに、地上の敵が遠くまで見通します。巣穴で休むと体力が早く回復し、おなかが60以上なら外でも少しずつ回復します。巣穴はスポーン地点の北にある土の山の中だけで、まわりの草原は隠れ場所ではありません（近くで隠れるには、ほかの場所と同じく草むらでしゃがむか倒木の下にもぐります）。敵は土の山から3.5 m以内まで来ると追跡をあきらめて引き返し、巣穴などの隠れ場所の中ではフンも残りません。敵の上限は季節ごとに増えます（春21・夏24・秋27・冬30）。

途中で力尽きても、ソロとホストは結果画面から最後のチェックポイント（章の始まり、目標の達成、森では季節の始まり）に戻ってやり直せます。巣穴に運び終えた巣材はそのまま残り、経過時間は続けて数えます。

季節の進行と数値は `src/campaign.ts`、基本ルールは `src/game.ts` の `RULES`、章ごとの地図・スクリプト・会話・見た目は `src/stages/<章>/` で定義しています。

## マップとステルス

フィールドは288×200 m（旧フィールド90×64 mの約10倍）です。西の「ふるさとの草原」（巣穴・スポーン）から、北→南に流れる小川をわたって、大樫の丘、北の台地と段々の崖、南の倒木の森、東の赤岩の砂地と大洞窟、北西の岩場へと広がります。地形・地物・食べもの・巣・捕食者の初期配置はすべて `src/stages/forest/map.ts` の静的データと固定シードから作られ（`src/map.ts` が今の章の地図への問い合わせをまとめます）、ホストのシミュレーション（`src/game.ts`）と描画（`src/world.ts`・`src/scene.ts`）が同じものを参照します。

### 高低差

- 高さは1 m格子のハイトマップ（`heightAt`）で、描画メッシュと同じ三角形分割で補間するため、見た目の地面と当たり判定が一致します。丘、北の台地（高さ9 mの崖）、東のゆるいスロープ、ウサギが一段ずつ跳んで登れる段々の崖（1段約1.3 m）、窪地（縁が盛り上がったお椀形）、深い小川と浅瀬があります。
- 傾きが約45°を超える斜面は歩いて登れず、さらに急な崖の面には立てずに滑り落ちます。ウサギのジャンプは約2.8 mなので段々の崖は登れますが、台地の崖は登れません。捕食者はジャンプしないため段差も登れず、台地へは東のスロープから回り込むしかありません。
- 捕食者の視線は地形・大きな岩・洞窟の壁でさえぎられます。丘の向こう側や窪地の底にいるウサギは、近くにいても見つかりません。

### 隠れ場所と通り道

| 場所                           | 使い方                                           | 効果・設計意図                                                                                                                                                                                      |
| ------------------------------ | ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| モグラのトンネル（2系統）      | 穴の上でC → 地下へ。別の出口の下でSpace → 地上へ | どの捕食者も入れず完全に隠れられる。西の系統は小川の下をくぐって草原と丘・森をつなぎ、ワニのいる浅瀬を避けて渡れる。分岐の貯蔵庫にニンジンがあるが2個だけなので、地下にこもり続けることはできない。 |
| 倒木の下                       | しゃがんだまま入る                               | 鷹を含む全員から見えない。キツネ・オオカミ・ワニは倒木をくぐれず回り道になる（ヘビはくぐれる）。ジャンプで飛び越えることもできる。下にベリーが置かれた倒木もある。                                  |
| 洞窟（東の大洞窟・台地の岩屋） | 入口から入る                                     | 暗く、しゃがまなくても隠れられる。中にいる捕食者にも4 m以内まで近づかれなければ見つからない。広い入口はオオカミも通れるが、細い入口はウサギとヘビしか通れない。                                     |
| 茂み                           | 入る／しゃがむ                                   | 立っていても上空の鷹からは見えない。しゃがめば地上の捕食者からも隠れられる。                                                                                                                        |
| 背の高い草・葦の帯             | しゃがむ                                         | 全員から隠れる。小川の両岸に帯状に生えていて、川沿いを隠れながら移動できる。                                                                                                                        |

### 捕食者

それぞれ縄張りの中心（初期位置か、生まれた巣）を持ち、巡回中は縄張りの外へ出ると戻ってきます（キツネ30 m、オオカミ38 m、鷹45 m、ヘビ20 m、ワニ40 m）。見つけ方は下の「ステルスと追跡」のとおりで、そこへ上の表の隠れ場所ごとの見え方と地形の遮りが加わります。追跡や探索で向かう先が崖・段差・倒木・岩・巣穴・深い水でふさがれていれば、そこで止まって回り道を探します。初期16匹、巣8か所から合計30匹まで増え、出現の速さは残っている巣の割合に比例します。ワニは水深のある所から出ず、新しいワニは巣に近い深みに現れます。

### 道しるべ

- 遠くからでも見える目印：大樫（丘の上）、赤岩の塔（東の砂地）、ふたご松（台地の上）、黄葉の白樺（ふるさとの巣穴のそば）。カメラは少し先を向くので、地平線と目印が画面に入ります。
- 右上に今いる地域名が出ます（地図は表示しません）。
- ウサギは白いまま、首輪と鈴がプレイヤーごとの色になります。色は赤・青・黄・紫・青緑・橙・桃・紺の8色で、ホストが参加時に同じ部屋で使われていない最初の色を選び、スナップショットの`color`（色番号）で全員に配ります（9羽目からは使用数の少ない色を再利用。`color`のない旧ホストのスナップショットではIDから決まる色）。同じ色を左上の「YOUR RABBIT」の丸にも使います。
- カメラは地形・大きな岩・洞窟の壁・トンネルの壁にめり込まないよう手前に寄り、ふさがれていれば左右に回り込みます。木・倒木・茂み・草はカメラを押し戻さず、カメラとウサギのあいだにかかる部分がくり抜かれて透けます（`src/see-through.ts`）。倒木の下にもぐると倒木が半透明になります。

### 通信と描画

- マップは送信しません。地形の高さは四則演算と平方根だけで計算するため、どのブラウザでも同じ値になります。スナップショットでは、食べものは出現中かどうかの`0`/`1`文字列、巣は体力の配列だけを送り、位置や種類は各クライアントがその章の地図から復元します。章（`stage`）・目標・ゲート・会話はIDと時刻だけを送り、車の位置は時刻から各クライアントが計算します。`stage`のない旧ホストのスナップショットは森として読みます。数値は小数第3位で丸めます。
- ゲストの先行移動（`GuestView`）もホストと同じ`moveRabbit`を使うため、坂・トンネル・倒木の下でも予測がずれません。
- 地形と、木・岩・茂み・草などのインスタンス描画は64 m四方のタイルに分け、画面外や影の範囲外のタイルを省きます。草は1枚の三角形で、揺れは頂点シェーダーで計算します。倒木・目印・洞窟などの静的な形は色ごとに1つのメッシュへまとめ、遠くの生き物と食べものは描きません。スポーン地点でのドローコールは約190、三角形は約9万です。
- 家と町の家具・小物は `src/stages/scenery-kit.ts` の部品キットで組み立て、部品ごとの色を頂点に焼き込んで、質感（粗さ・金属感など）ごとに1つのメッシュへまとめます。家は家の中と庭に、町は40 m四方ごとに分けてまとめ、画面外や影の範囲外の分を省きます。果物・缶・取っ手などの小さな部品は影を落としません。スポーン地点でのドローコールは家で約30、町で約70です。

## ステルスと追跡

敵の知覚と追跡は`src/stealth.ts`にまとめた純粋関数で計算します。地形の高さと視線の遮りは`Terrain`（`heightAt`・`sightLine`）として差し替えられ、既定では`src/game.ts`の`mapTerrain`（共有マップの地形・大きな岩・洞窟の壁で視線が切れ、ウサギから3 m以内の木の幹が視線にかかると見えにくくなる）を使います。

- **見つかる距離は3段階です。** 敵ごとの視認距離（キツネ・オオカミ・ワニ13m、タカ18m、ヘビ7m）に、しゃがみ×0.6、しゃがまずに草むら×0.7、木の陰×0.45（幹から1.5 m以内にぴったり隠れると×0.2、幹が2本以上かかるとさらに掛け合わせ、下限×0.1）を掛けたものを実効距離とします。正面の視野（約200°）で、実効距離の40%以内なら即座に発見（「！」）、実効距離以内なら疑い（「？」）、1.6倍以内なら気配だけを感じて最後に見かけた地点へうろつきながらゆっくり探しに来ます。2m以内は向きに関係なく発見します。どの隠れ場所で誰から見えなくなるかは「隠れ場所と通り道」の表のとおりです。
- **木のあいだを抜ける。** 地上の敵は、追跡中に木の幹が1.6 m以内にあると幹をよけながら走るため、速さが6割に落ちます。追われたら森の木のあいだを抜けると距離をかせげます。
- **疑いメーター。** 「？」の間は敵がウサギの方を向き、少しずつ近寄ります。メーターは近いほど速く溜まり（内側で約1.5秒、外側で約3秒）、満ちると発見です。途中で草むらや木の陰に隠れると毎秒0.35ずつ減り、敵は最後の目撃地点を約4.5秒調べてから巡回に戻ります。見失った追跡中の敵も同じように探してから諦めます。
- **発見の演出。** 発見時は敵の頭上に「！」が飛び出し、狙われたプレイヤーの画面に赤いフラッシュとビネット、全員に警告音が鳴ります。「？」は黄色の吹き出しとメーターで表示し、狙われたプレイヤーには控えめな音と黄色の縁取りが出ます。探索中の敵には薄い「？」が付きます。表示はホストの状態から全員の画面に描かれ、効果音はWebAudioで合成したオリジナル音で♪ボタンのミュートに従います。
- **フン。** ウサギは5〜12秒のランダムな間隔でフンを落とします。ジャンプ中やダッシュ中に落ちたフンは進行方向へ転がり、斜面では高いほうから低いほうへ転がります。キツネ・オオカミ・ヘビは4.5m以内の新しいフンを嗅ぎつけると、同じウサギのより新しいフンを古い順にたどります。匂いは40秒で消え、次のフンが22mより遠い場合も足どりが途切れるため、必ずウサギまでたどり着くとは限りません。フンは最大32個・90秒で古いものから消え、同期データは位置と時刻だけです。トンネルの中に落ちたフンは転がらず、地上の敵には嗅げません。
- **匂いを断つ。** 水に入るか、砂地（東の砂地と、森・丘・草原の3か所の砂場）で動かずにCを2秒長押しして砂浴びすると、それより前のフンから後のフンへの追跡は20%の確率でしか続きません。
- **飛ぶ敵の動き。** タカは旋回速度・加速度・上昇（毎秒2.5m）と降下（毎秒5m）の上限に従って飛び、獲物を見失っても一瞬で消えず、上昇して最後の地点の上空を旋回しながら探します。巡航・探索の高さは地面からの高さなので、丘や台地の上も同じように飛びます。ホストの計算そのものが連続なので、ゲスト側の補間（`src/guest-view.ts`）でも瞬間移動しません。

## 検証とビルド

```sh
npm run test:rabbiters
npm run e2e:rabbiters
npm run build:rabbiters
```

ユニットテストの共通ボット（格子の経路探索と慎重な行動）は `tests/bot.ts` にあります。第1章のボット（段差のジャンプ・家具の下でしゃがむ・目標ごとの行動）は `tests/house-bot.ts`、所要時間テストは `tests/house.test.ts`（脅威なし約8.6分、脅威ありの慎重なボットで3シード20〜40分）です。E2Eは `tests/rabbiters-*.spec.ts` をすべて実行し、毎回専用のサーバー（既定5193）を起動し、既存サーバーは再利用しません。ポートが使用中なら`E2E_PORT=5393 npm run e2e:rabbiters`のように変更します。起動中の開発サーバーで試す場合だけ`E2E_REUSE_SERVER=1`を付けます。

ブラウザテストにはPlaywrightのChromiumが必要です。既存のChromiumを使う場合は`PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`を指定できます。独立ビルドの出力先は`dist/rabbiters/`です。通常のPagesビルドにも含まれ、ゲーム一覧から開けます。

Rabbitersは公式リリース`moq-wasm@0.1.0`を`package-lock.json`の整合性ハッシュ付きで使用します。Pagesのライセンス通知には、このリリースのソースとロックファイルから調べた依存関係を旧SDKとは別に記載しています。依存一覧は余分なビルド依存も含む概算で、バイナリ内の構成を個別に検証したものではありません。ゲーム内の3Dモデルは自作で、対応する原画とモーション資料は`art-source/`に保管し、Pagesには含めません。
