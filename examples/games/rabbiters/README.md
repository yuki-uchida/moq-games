# ウサギ・イヤ・ラビット (Rabbiters)

ウサギになって食料を探し、捕食者から逃れながら、誰か一羽の出産を目指す協力サバイバルゲームの試作です。ホストがゲームを計算し、MoQ Relayは入力と状態を中継します。ホストがいなくなった場合の引き継ぎはありません。

## 起動

Node.js 24とnpmを用意し、リポジトリ直下で実行します。初回は既存ゲーム用SDKのセットアップと、Rabbiters用`moq-wasm`のリリースtarballを含む依存関係のインストールが必要です。

```sh
node scripts/setup-sdk.mjs
npm ci --ignore-scripts
npm run dev:rabbiters
```

`http://127.0.0.1:5193/`を開きます。ソロならRelayは不要です。協力プレイでは参加者が同じHTTPSのMoQ Relay URLとルーム名を入力し、一人が「ルームを作る」、残りが「ルームに参加」を選びます。Relayの初期値は`https://relay.moqt.research.skyway.io`です。RelayはMoQのnamespace watch・announce・publish・subscribeをサポートし、`anon/rabbiters-v1/<room>`を使用できる必要があります。WebTransportを使えるブラウザと、ブラウザが信頼するRelayのTLS証明書が必要です。ルーム名やプレイヤーIDは認証ではないため、信頼できるRelayと参加者で利用してください。

別の端末から参加する場合は、ゲーム自体も各端末からアクセスできるHTTPSの配信先に配置してください。`127.0.0.1`は開いている端末自身を指します。

更新前のホストからは、食べものの種類や新しいステルス情報がない状態も受け取れます。新しいホストは、旧参加者にも読める捕食者の状態と、新参加者向けの詳細状態を送ります。古いページでは捕食者の疑い表示が省略される場合があるため、全員がページを再読み込みすると最新の表示で遊べます。ただしマップ拡張（288×200 m）より前のホスト・参加者とは地形と食べものの配置が異なるため、同じルームでは遊べません（参加者側は状態を受け取らず待機します）。

PCはWASD／矢印で移動、Spaceでジャンプ、Shiftでダッシュ、Cでしゃがむ（砂地で長押しすると砂浴び。モグラの穴の上ではCで地下へもぐり、出口の下でSpaceを押すと地上へ出ます）、E長押しで巣の破壊または仲間の救助、フィールドをクリックするとマウスカーソルが固定され（Pointer Lock）、ボタンを押さずにマウスを動かすだけでTPS視点が回転します。Escで解除でき、Pointer Lockが使えない場合は従来どおりドラッグで回転します。タッチ操作は画面のスティックとボタンを使い、フィールドのドラッグで視点を回転できます。画面上部の♪ボタンでBGMと効果音を切り替えられます。

食べものに近づくと自動で食べます。6回以上食べ、約5分の成長と十分な栄養を得ると妊娠し、さらに約10分生きのびると出産します。妊娠中は移動が遅く、空腹が早く進みます。空腹が尽きると体力が減り出産も進まないため、妊娠中にも食料が必要です。草むら・茂み・倒木の下・浅瀬でしゃがむ、洞窟や木のうろ・巣穴・モグラのトンネルに入る、丘や窪地の陰に回るなどして敵から隠れられます（詳しくは下の「マップとステルス」）。巣の卵を壊すと敵の追加出現が減り、すべて壊すと止まります。誰か一羽が出産できれば全員の勝利です。

### 食べもの

6種類あり、食べると満腹度が回復します（どれも1回として数えるため、妊娠条件の「6回以上食べる」は共通です）。

| 種類       | 回復量 | 置き場所                                   |
| ---------- | ------ | ------------------------------------------ |
| ニンジン   | 28     | 草地・砂地、モグラの貯蔵庫（トンネルの中） |
| クローバー | 24     | 草地                                       |
| タンポポ   | 24     | 草地                                       |
| キャベツ   | 34     | 開けた草地・砂地                           |
| リンゴ     | 32     | 切り株の上（ジャンプで取る）               |
| ベリー     | 26     | 倒木の森と洞窟の中                         |

回復量は `src/food.ts` の `FOOD_KINDS`、置き場所と種類は `src/map.ts` の `FOODS` で定義しています。

## マップとステルス

フィールドは288×200 m（旧フィールド90×64 mの約10倍）です。西の「ふるさとの草原」（巣穴・スポーン）から、北→南に流れる小川をわたって、大樫の丘、北の台地と段々の崖、南の倒木の森、東の赤岩の砂地と大洞窟、北西の岩場へと広がります。地形・地物・食べもの・巣・捕食者の初期配置はすべて `src/map.ts` の静的データと固定シードから作られ、ホストのシミュレーション（`src/game.ts`）、描画（`src/world.ts`・`src/scene.ts`）、ミニマップ（`src/minimap.ts`）が同じものを参照します。

### 高低差

- 高さは1 m格子のハイトマップ（`heightAt`）で、描画メッシュと同じ三角形分割で補間するため、見た目の地面と当たり判定が一致します。丘、北の台地（高さ9 mの崖）、東のゆるいスロープ、ウサギが一段ずつ跳んで登れる段々の崖（1段約1.3 m）、窪地（縁が盛り上がったお椀形）、深い小川と浅瀬があります。
- 傾きが約45°を超える斜面は歩いて登れず、さらに急な崖の面には立てずに滑り落ちます。ウサギのジャンプは約2.8 mなので段々の崖は登れますが、台地の崖は登れません。捕食者はジャンプしないため段差も登れず、台地へは東のスロープから回り込むしかありません。
- 捕食者の視線は地形・大きな岩・洞窟の壁でさえぎられます。丘の向こう側や窪地の底にいるウサギは、近くにいても見つかりません。

### 捕食者

それぞれ縄張りの中心（初期位置か、生まれた巣）を持ち、巡回中は縄張りの外へ出ると戻ってきます（キツネ30 m、オオカミ38 m、鷹45 m、ヘビ20 m、ワニ40 m）。見つけ方は下の「ステルスと追跡」のとおりで、そこへ上の表の隠れ場所ごとの見え方と地形の遮りが加わります。追跡や探索で向かう先が崖・段差・倒木・岩・巣穴・深い水でふさがれていれば、そこで止まって回り道を探します。初期16匹、巣8か所から合計30匹まで増え、出現の速さは残っている巣の割合に比例します。ワニは水深のある所から出ず、新しいワニは巣に近い深みに現れます。

### 道しるべ

- 遠くからでも見える目印：大樫（丘の上）、赤岩の塔（東の砂地）、ふたご松（台地の上）、黄葉の白樺（ふるさとの巣穴のそば）。カメラは少し先を向くので、地平線と目印が画面に入ります。
- 右上のミニマップは北が上で、自分の向き（矢印）と視界、仲間、残っている巣、トンネルの経路と出口、洞窟、目印を表示し、下に今いる地域名が出ます。
- ウサギは白いまま、首輪と鈴がプレイヤーごとの色になります。色は赤・青・黄・紫・青緑・橙・桃・紺の8色で、ホストが参加時に同じ部屋で使われていない最初の色を選び、スナップショットの`color`（色番号）で全員に配ります（9羽目からは使用数の少ない色を再利用。`color`のない旧ホストのスナップショットではIDから決まる色）。同じ色を左上の「YOUR RABBIT」の丸、ミニマップの自分の矢印と仲間の点（倒れた仲間は赤い縁）にも使います。
- カメラは地形・岩・木・倒木・洞窟の壁・トンネルの壁にめり込まないよう手前に寄り、ふさがれていれば左右に回り込みます。倒木の下にもぐると倒木が半透明になります。

### 通信と描画

- マップは送信しません。地形の高さは四則演算と平方根だけで計算するため、どのブラウザでも同じ値になります。スナップショットでは、食べものは出現中かどうかの`0`/`1`文字列、巣は体力の配列だけを送り、位置や種類は各クライアントが地図から復元します。数値は小数第3位で丸めます。
- ゲストの先行移動（`GuestView`）もホストと同じ`moveRabbit`を使うため、坂・トンネル・倒木の下でも予測がずれません。
- 地形と、木・岩・茂み・草などのインスタンス描画は64 m四方のタイルに分け、画面外や影の範囲外のタイルを省きます。草は1枚の三角形で、揺れは頂点シェーダーで計算します。倒木・目印・洞窟などの静的な形は色ごとに1つのメッシュへまとめ、遠くの生き物と食べものは描きません。スポーン地点でのドローコールは約140、三角形は約6万です。

## ステルスと追跡

敵の知覚と追跡は`src/stealth.ts`にまとめた純粋関数で計算します。地形の高さと視線の遮りは`Terrain`（`heightAt`・`sightLine`）として差し替えられ、既定では`src/game.ts`の`mapTerrain`（共有マップの地形・大きな岩・洞窟の壁で視線が切れ、ウサギのそばの木の幹は部分的に遮る）を使います。

- **見つかる距離は3段階です。** 敵ごとの視認距離（キツネ・オオカミ・ワニ13m、タカ18m、ヘビ7m）に、しゃがみ×0.6、しゃがまずに草むら×0.7、木の陰×0.45を掛けたものを実効距離とします。正面の視野（約200°）で、実効距離の40%以内なら即座に発見（「！」）、実効距離以内なら疑い（「？」）、1.6倍以内なら気配だけを感じて最後に見かけた地点へうろつきながらゆっくり探しに来ます。2m以内は向きに関係なく発見します。どの隠れ場所で誰から見えなくなるかは「隠れ場所と通り道」の表のとおりです。
- **疑いメーター。** 「？」の間は敵がウサギの方を向き、少しずつ近寄ります。メーターは近いほど速く溜まり（内側で約1.5秒、外側で約3秒）、満ちると発見です。途中で草むらや木の陰に隠れると毎秒0.35ずつ減り、敵は最後の目撃地点を約4.5秒調べてから巡回に戻ります。見失った追跡中の敵も同じように探してから諦めます。
- **発見の演出。** 発見時は敵の頭上に「！」が飛び出し、狙われたプレイヤーの画面に赤いフラッシュとビネット、全員に警告音が鳴ります。「？」は黄色の吹き出しとメーターで表示し、狙われたプレイヤーには控えめな音と黄色の縁取りが出ます。探索中の敵には薄い「？」が付きます。表示はホストの状態から全員の画面に描かれ、効果音はWebAudioで合成したオリジナル音で♪ボタンのミュートに従います。
- **フン。** ウサギは5〜12秒のランダムな間隔でフンを落とします。ジャンプ中やダッシュ中に落ちたフンは進行方向へ転がり、斜面では高いほうから低いほうへ転がります。キツネ・オオカミ・ヘビは4.5m以内の新しいフンを嗅ぎつけると、同じウサギのより新しいフンを古い順にたどります。匂いは40秒で消え、次のフンが22mより遠い場合も足どりが途切れるため、必ずウサギまでたどり着くとは限りません。フンは最大32個・90秒で古いものから消え、同期データは位置と時刻だけです。トンネルの中に落ちたフンは転がらず、地上の敵には嗅げません。
- **匂いを断つ。** 水に入るか、砂地（東の砂地と、森・丘・草原の3か所の砂場）で動かずにCを2秒長押しして砂浴びすると、それより前のフンから後のフンへの追跡は20%の確率でしか続きません。
- **飛ぶ敵の動き。** タカは旋回速度・加速度・上昇（毎秒2.5m）と降下（毎秒5m）の上限に従って飛び、獲物を見失っても一瞬で消えず、上昇して最後の地点の上空を旋回しながら探します。巡航・探索の高さは地面からの高さなので、丘や台地の上も同じように飛びます。ホストの計算そのものが連続なので、ゲスト側の補間（`src/guest-view.ts`）でも瞬間移動しません。

## 検証とビルド

```sh
npm run test:rabbiters
npm run e2e:rabbiters
npm run build:rabbiters
```

E2Eは毎回専用のサーバー（既定5193）を起動し、既存サーバーは再利用しません。ポートが使用中なら`E2E_PORT=5393 npm run e2e:rabbiters`のように変更します。起動中の開発サーバーで試す場合だけ`E2E_REUSE_SERVER=1`を付けます。

ブラウザテストにはPlaywrightのChromiumが必要です。既存のChromiumを使う場合は`PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`を指定できます。独立ビルドの出力先は`dist/rabbiters/`です。通常のPagesビルドにも含まれ、ゲーム一覧から開けます。

Rabbitersは公式リリース`moq-wasm@0.1.0`を`package-lock.json`の整合性ハッシュ付きで使用します。Pagesのライセンス通知には、このリリースのソースとロックファイルから調べた依存関係を旧SDKとは別に記載しています。依存一覧は余分なビルド依存も含む概算で、バイナリ内の構成を個別に検証したものではありません。ゲーム内の3Dモデルは自作で、対応する原画とモーション資料は`art-source/`に保管し、Pagesには含めません。
