# マモノ陣形

4匹の小さなマモノが冒険者ギルドに挑む、最大4人の協力アクションです。剣士・魔法使い・弓使い・僧侶の4匹は、ステージごとに姿を変えます。

| ステージ               | 主人公   | Space のアクション           | 協力技             | 主な仕掛け                                        | ボス                     |
| ---------------------- | -------- | ---------------------------- | ------------------ | ------------------------------------------------- | ------------------------ |
| 1 ぷるぷる草原と古城跡 | スライム | ジャンプ                     | ジャンボ・プレス   | 重い岩とどんぐり、2つの床スイッチ、4つの水晶      | 盾騎士団長ガルド         |
| 2 地下水路と穀物庫     | ネズミ   | ダッシュ（ネズミ穴をくぐる） | チューチュー大行進 | 水流、離れた2つのバルブ、巨大チーズ、バリケード   | 猫使いの魔女ミルダと大猫 |
| 3 風鳴りの崖と時計塔   | カラス   | 長押しで飛ぶ                 | 黒羽の大旋風       | 雲海、上昇気流と風、風車と跳ね橋、4つの鐘、金の鐘 | 竜騎士ヴァルク           |
| 4 月影の森と白銀の砦   | ウルフ   | 遠吠え                       | 月下群狼陣         | 夜の暗さ、月石、氷、丸太の破城槌、氷の壁          | 勇者レオン               |

## 遊び方

- 仲間と近づくと**陣形**になります（2人: ペア陣、3人: 三角陣、4人: 四方陣）。陣形中は攻撃が強くなり、受けるダメージが減ります。
- クリックを長押しして光ったら離すと、ひとりなら職業の技、陣形中なら種族ごとの**協力技**になります。協力技でしか壊せない岩や壁、止められないボスもいます。
- 重い岩、どんぐり、チーズ、金の鐘、丸太は、陣形の人数が足りないと動きません。
- 床スイッチ、水晶、バルブ、鐘、月石のように、分かれて同時に操作しないと解けない仕掛けもあります。「せーの！」の合図を使ってください。

| 操作            | 内容                                   |
| --------------- | -------------------------------------- |
| WASD / 矢印キー | 移動                                   |
| マウス          | ねらう方向                             |
| クリック        | 攻撃（運んでいる小物は投げる）         |
| クリック長押し  | ため攻撃。陣形中は協力技               |
| Space           | 種族アクション（上の表）               |
| E               | 持ち上げる・置く・つかむ・レバー・話す |
| Q               | 自分の仲間に「待て」「ついてこい」     |
| Tab             | 操作するマモノを交代                   |
| F               | 「せーの！」の合図（3・2・1・GO）      |
| Esc             | メニュー（ひとりのときは一時停止）     |

ゲームパッドにも対応しています。ひとりのときは4匹すべてを指揮し、仲間は陣形を組んでついてきます。

## みんなで遊ぶ

「ルームを作る」でルームコードを決め、友だちは同じコードで「ルームに参加」します。通信はMoQリレー（`?relayUrl=` で変更可能）を使い、ホストがゲームを進めます。参加者が4人に満たない職業は仲間（AI）が担当し、5人目以降は観戦になります。

## 開発

```sh
npm run dev:mamono-jinkei        # http://127.0.0.1:5197
npm run test:mamono-jinkei       # シミュレーション・ドット絵・音のテスト
npm run e2e:mamono-jinkei        # ブラウザテスト（E2E_PORT で別ポート）
npm run art:mamono-jinkei        # ドット絵の確認用PNGを .build/mamono-jinkei-art/ に出力
```

ドット絵（64×64）・音楽・効果音はすべてコードで生成しており、画像や音声のファイルはありません。設計は [DESIGN.md](DESIGN.md) にあります。
