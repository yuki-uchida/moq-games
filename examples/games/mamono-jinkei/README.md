# マモノ陣形

4匹の小さなマモノが冒険者ギルドに挑む、最大4人の協力アクションです。ステージごとに主人公の姿が変わります（スライム → ネズミ → カラス → ウルフ）。現在遊べるのはステージ1「ぷるぷる草原と古城跡」（スライム）です。

## 遊び方

- 仲間と近づくと**陣形**になります（2人: ペア陣、3人: 三角陣、4人: 四方陣）。陣形中は攻撃が強くなり、受けるダメージが減ります。
- クリックを長押しして光ったら離すと、ひとりなら職業の技、陣形中なら**協力技**（スライムは「ジャンボ・プレス」）になります。
- 重い岩や大きなどんぐりは、陣形の人数が足りないと動きません。
- 床スイッチや水晶のように、分かれて同時に操作しないと解けない仕掛けもあります。「せーの！」の合図を使ってください。

| 操作            | 内容                                   |
| --------------- | -------------------------------------- |
| WASD / 矢印キー | 移動                                   |
| マウス          | ねらう方向                             |
| クリック        | 攻撃（運んでいる小物は投げる）         |
| クリック長押し  | ため攻撃。陣形中は協力技               |
| Space           | 種族アクション（スライムはジャンプ）   |
| E               | 持ち上げる・置く・つかむ・レバー・話す |
| Q               | 自分の仲間に「待て」「ついてこい」     |
| Tab             | 操作するマモノを交代                   |
| F               | 「せーの！」の合図（3・2・1・GO）      |
| Esc             | メニュー（ひとりのときは一時停止）     |

ゲームパッドにも対応しています。ひとりのときは4匹すべてを指揮し、仲間は陣形を組んでついてきます。

## みんなで遊ぶ

「ルームを作る」でルームコードを決め、友だちは同じコードで「ルームに参加」します。通信はMoQリレー（`?relayUrl=` で変更可能）を使い、ホストがゲームを進めます。参加者が4人に満たない職業は仲間（AI）が担当し、5人目以降は観戦になります。

## 開発

```sh
npm run dev:mamono-jinkei        # http://127.0.0.1:5197
npm run test:mamono-jinkei       # シミュレーション・ドット絵・音のテスト
npm run e2e:mamono-jinkei        # ブラウザテスト（E2E_PORT で別ポート）
npm run art:mamono-jinkei        # ドット絵の確認用PNGを .build/mamono-jinkei-art/ に出力
```

ドット絵（64×64）・音楽・効果音はすべてコードで生成しており、画像や音声のファイルはありません。設計は [DESIGN.md](DESIGN.md) にあります。
