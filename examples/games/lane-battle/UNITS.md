# うんこ大惨事 ユニット設定書

全26ユニット（うんこ6・特殊12・清掃軍団8）の **攻撃モーション・攻撃範囲・特殊効果・くらいモーション・死亡モーション** を定義する。数値は初期設計値で、バランス検証（`campaign.test.mjs` などの既存しきい値）を満たすために各値を ±25% まで調整してよい。ただし各ユニットの範囲の形・効果の種類・演技の内容（＝そのユニットらしさ）は変えない。調整した最終値はこの文書に反映する。

キャンペーン調整で変更した値には初期設計値を併記する。

## 1. 共通ルール

### 1.1 攻撃範囲の種類

レーンは1次元（x）なので、範囲は「どの区間の敵に当たるか」と「何体まで・何%で当たるか」で表す。距離はすべて攻撃者の向き（前方）を正とするレーン単位。`range` は従来どおり「攻撃を始める距離（射程）」で、変更しない。

| 種類        | 定義                                                                                           | 使うユニット                                                                                                       |
| ----------- | ---------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| 単体        | 交戦中の相手1体（相手がいなければ敵陣）                                                        | カチカチ・ラーメン・夜ふかし・お酒・激辛カレー・牛乳・生ガキ・アイス・エナジー・清掃員・ヨーグルト・白湯・和式便器 |
| 着弾円 r    | 着弾した相手の x から ±r の敵全員                                                              | ビチビチ・焼肉・ニンニク・整腸剤・下痢止め                                                                         |
| 前方帯 a..b | 攻撃者からの前方距離が a〜b の敵を近い順に最大 N 体、順番ごとの倍率で                          | ゲリラ（突進）・ドデカ（腹ドン）・モップ（なぎ払い）                                                               |
| 冷風コーン  | 前方帯 0..range の敵を近い順に最大3体。距離に応じて到達が遅れる（下記）                        | 冷房                                                                                                               |
| 貫通線      | 前方帯 0..range の敵を近い順に最大3体。到達は距離に比例                                        | 洋式便器                                                                                                           |
| 衝撃波      | 交戦中の相手の位置から奥へ80を地面を走る波が順に打つ。到達 = 接触 + (距離−相手の距離) / 600 秒 | 宿便大王                                                                                                           |
| 周囲リング  | 攻撃者の x から ±r の敵全員（最大5体）                                                         | 二郎系ラーメン                                                                                                     |
| 跳弾        | 主目標に命中後、そのさらに奥（攻撃者から遠い側）70以内の最も近い敵へ転がって二撃目             | コロコロ                                                                                                           |

- 交戦中の相手（主目標）は、どの範囲でも必ず1体目として100%で当たる（懐に入られても外れない）。範囲はその他の敵を近い順に加える。
- 敵陣（砦）が目標のときは主ダメージのみを与え、範囲の追加対象や砦への状態異常は発生しない。ゾーンは砦手前の着弾点に置かれる。
- 冷風コーン・貫通線の各対象への到達時刻は「放出 + 0.12 × (距離 / range)」秒。到達までに対象が倒れたら、その対象への命中は消える（主目標の従来ルールと同じ）。
- 範囲の追加対象（2体目以降・跳弾・衝撃波・玉突き）にも EXP の与ダメ記録（`hitters`）を付ける。

- **行動不能系**（凍結・スタン・打ち上げ・千鳥足）は重ならない。かかっている間とその終了後 1.2 秒は、新しい行動不能系を受けない（耐性）。
- **重量級**（ドデカ・宿便大王・二郎系・和式便器・下痢止め）は、行動不能系の時間・ノックバック・引き寄せ・滑りの距離が半分、処刑のしきい値が10%。
- **不動**（ドデカ）は、ノックバック・引き寄せ・滑り・打ち上げを受けない。
- 移動速度の低下は最も強いものだけが効く（掛け算しない）。
- ダメージ計算順: 攻撃力 × 会心(2.5) × 攻撃ダウン(0.7) × 範囲倍率 × 防御ダウン(1.2) × カチカチ装甲(0.7)。
- 攻撃間隔の変化（眠気・号令・カフェイン加速）は「次の攻撃を予約する瞬間」に決まり、途中では変わらない。描画は実際の残り時間（攻撃タイマー）を使うので、接触フレームは常にシミュレーションの命中と一致する。
- 行動不能中は攻撃タイマーと攻撃位相が進まない。解けると止まった位置から再開する。
- 同一 tick 内でも死亡や移動で射程内に入れば、攻撃可能なユニットはその時点で攻撃する。決着前に倒した敵の報酬・経験値は決着時に確定する。
- ゾーンは発生源1体につき1つ（新しいもので置き換え）、発生源が倒れても時間まで残る。
- 乱数は全て `s.rng` から決まった順番で引き、同じシードなら同じ結果になる。

### 1.3 演技の共通ルール

- 命中（または発射）はシミュレーションの攻撃位相0。各キャラはそこで接触ポーズを保持する。構え（溜め）はゆっくり、振り下ろし・突き出しは数フレームで速く、接触ホールド、反動、戻りの5段階を必ず持つ。
- 重いユニットは溜めと接触ホールドを長く、軽いユニットは短く（下表「テンポ」）。溜め + 戻り は攻撃間隔より短く、最短の攻撃間隔（号令・カフェイン加速の適用後）でも崩れないこと。
- ゲーム内の実寸（1280×800 でキャラの高さ約55px、縦長390×844でも）で、溜めの極値と接触ポーズのシルエットがはっきり違うこと。主な打撃部位は溜め→接触で体高の25%以上動き、体（腰）も 0.12 以上の移動か 0.25rad 以上の回転で攻撃を支える。小道具だけが動く攻撃は不可。
- くらいモーションは命中フレームで始まり、0.05秒以内にピーク、0.55秒以内（重量級0.7秒）に収まる。強さ（power）で振れ幅が変わる。全ユニット固有の演技を持つ。
- 死亡モーションはユニットごとの長さ（0.8〜1.15秒）。始まりの衝撃→そのキャラ固有の崩れ方→着地・静止→最後の約25%でフェード。外れて飛ぶ部品（兜・王冠・キャップ・房など）は意図した演出で、それ以外の部品が欠けたり、ちぎれたり、関節が外れたりしてはいけない。
- 色の約束: うんこ軍の打撃エフェクトは茶・金系、清掃軍団は白・水色系。状態異常は付与元に関わらず効果ごとに固定色（下表）。
- 状態異常バッジは HP バーの上に最大3個、キャンバスで描く図形（絵文字は使わない）。優先順: 行動不能系 > 毒 > やけど > 激辛マーク > 防御ダウン > 攻撃ダウン > 眠気 > 鈍足 > 号令。

| ---------- | ------------------------------------------------ |

| 凍結       | 水色の半透明の氷ブロックで全身を包む、体が青白く |

### 1.5 画面表示

- 各ユニット型に `area`（範囲の短い名前）と `effect`（効果名）と `effectLine`（一文の説明）を持たせ、作戦室の編成カード・購入カード・新しい仲間の報告・召喚カードのツールチップに表示する（例: 「近接・前方3体 ／ 押し返し」）。
- 攻撃の範囲は、命中時のエフェクトの形で毎回わかるようにする（コーン・水流ビーム・地面を走る衝撃波・周囲リング・なぎ払いの弧・着弾円・転がるつぶて）。
- ゾーンは床に描き、ユニットより下に重ねる。命中エフェクトはユニットより上、バッジは HP バーの上。
- `prefers-reduced-motion` では画面揺れを無効にし、粒子を減らす。一時停止中はエフェクトも止まる（時間はシミュレーション時刻で進める）。
