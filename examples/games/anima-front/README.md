# アニマフロント (ANIMA FRONT)

人類が姿を消した世界で、知恵を得た動物たちが人類の遺した兵装〈アンティーク〉を手に、星々のアニマを喰らう侵略者〈蝕〉と戦う
3D アクションシューターです。空いた席はすべてボットが埋めるので、ひとりでも遊べます。

- **防衛任務 (PvE)**: 4匹の小隊で、押し寄せる蝕獣・蝕機・クロヅメ連合の獣兵と戦う全5任務（難易度 訓練 / 正規 / 決死）。
- **三つ巴演習 (PvP)**: 4匹 × 3チームの6分間の撃破戦。残り60秒は撃破ポイント2倍。
- **訓練場**: 8段階のチュートリアルと、アニマ無限で構成を試せる自由練習。

設計の詳細は [DESIGN.md](DESIGN.md) にあります。

## アニマと16スロット

- アニマは体力と弾薬をまとめたもの。被弾でも、武器・防具・小道具を使っても減ります。0になるとアーマーが崩壊し、帰巣（基地へ転送）します。
- 動物ごとに最大アニマが違います（ハムスター 70 〜 ヒグマ 140）。
- 部隊編成では16個のスロットに、近接・遠隔・防具・強化・小道具のアンティークを自由に割り振れます。消費の激しいものばかりにすると
  すぐにアニマが尽きるので、画面の「推定継戦時間」を見ながら、消費の少ない武器も組み合わせましょう。
- 使うアンティークは右手と左手に1つずつ持ちます。左クリックで右手、右クリックで左手を使います。

## 開発

リポジトリのルートで実行します（SDK と依存関係の準備はルートの README を参照）。

```sh
npm run dev:anima-front        # http://127.0.0.1:5198/
npm run test:anima-front       # ユニットテスト（シミュレーション・マップ・モデル・描画・音・画面）
npm run e2e:anima-front        # ブラウザテスト（Playwright）
npm run build:anima-front      # このゲームだけのビルド
```

確認用のツール（出力は `.build/anima-front/`）:

```sh
node scripts/anima-front-maps.mjs     # 全マップの俯瞰図と斜め図
node scripts/anima-front-models.mjs   # 動物・アンティークのモデル一覧（review.html）
node scripts/anima-front-render.mjs   # 描画のテストシーン（render-test.html）
node scripts/anima-front-audio.mjs    # 効果音と曲のオフライン書き出しと計測
```

モデル・テクスチャ・音楽・効果音はすべてコードで生成しており、画像・音声・モデルのファイルは使っていません。
