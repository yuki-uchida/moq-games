# Model kit (`src/models`)

Every model of アニマフロント is generated by code: shapes are sculpted as signed-distance fields (SDF), meshed,
simplified and shaded with a toon ramp. Nothing is loaded from files. `createModelKit({ quality })` (index.ts)
implements the `ModelKit` contract of `api.ts`.

| file / folder                 | role                                                                                         |
| ----------------------------- | -------------------------------------------------------------------------------------------- |
| `sdf/sculpt.ts`               | shapes and the `Sculpt` builder (add / sub / inter / paint / emboss)                         |
| `sdf/field.ts`                | compiled field: fast distance loop, colour layers, skin weights                              |
| `sdf/mesher.ts`               | surface nets on culled 4³ blocks, Newton projection, AO, skin weights; `traceSurface`        |
| `sdf/simplify.ts`             | quadric edge-collapse simplification that keeps colour contours                              |
| `sdf/regions.ts`              | shader-drawn paint regions (markings) packed into a float DataTexture                        |
| `sdf/geometry.ts`             | `toGeometry`, `bakeModel` (rigid model + regions), `geometryHash`                            |
| `materials.ts`                | toon material (3-band ramp, rim, masks, team pattern, flash, cloak, hologram), outline, eyes |
| `rig.ts`                      | the shared 24-bone skeleton and chibi body plans                                             |
| `species/`                    | the eight animals (`mammals.ts`, `birds.ts`), shared blocks and the ARK uniform (`body.ts`)  |
| `face.ts`, `gear.ts`          | eyes / brows / mouths placed by tracing the head; passive gear and the クロヅメ scarf        |
| `animation.ts`, `motion.ts`   | procedural animation from `CharacterPose`; how each antique is held and used                 |
| `assembly.ts`, `hull.ts`      | merged draw calls: body + parts + face lines + gear in one skinned mesh, single-draw outline |
| `character.ts`                | `CharacterModel` (merged body, eyes, paws, looks, level of detail)                           |
| `items/`                      | the 34 antiques (`melee`, `ranged`, `gadgets`, `emblems`) and `ItemModel` (one draw call)    |
| `foes/`                       | crowd foe rigs: material, bake/tube helpers, `creatures/`, `machines` (+ `machines/`)        |
| `bosses/`, `props/`, `shots/` | クイツクシ and ゴウテツ, deployables and map props, projectile looks                         |

## Sculpting a model

Units are metres, **Y is up, models face +Z**, the left side is +X. A model is an ordered list of operations:

```ts
import { capsule, cone, ellipsoid, plane, scaled, Sculpt, slab, sphere } from './sdf/sculpt'

const s = new Sculpt()
s.add(ellipsoid([0, 0.5, 0], [0.2, 0.18, 0.16]), { color: 0xe38b4b, bone: 'chest' }) // body
s.add(sphere([0, 0.8, 0], 0.2), { color: 0xe38b4b, bone: 'head', k: 0.06 }) // k = smooth blend radius
s.add(scaled(cone([0.1, 0.95, 0], [0.18, 1.1, 0], 0.07, 0.015), [1, 1, 0.45]), { color: 0xe38b4b }) // flat ear
s.sub(plane([0, 0, 0], [0, 1, 0]), { k: 0.01 }) // cut everything below y = 0
s.paint(ellipsoid([0, 0.45, 0.14], [0.1, 0.15, 0.08]), { color: 0xfaebd3 }) // a marking: colour only
s.emboss(slab([0, 0.3, 0], [0, 1, 0], 0.025), { amount: 0.007, soft: 0.01, color: 0x27355f }) // raised strap
```

Shapes: `sphere`, `ellipsoid`, `cone` (rounded cone; `capsule` when both radii match), `box` (rounded), `torus`,
`arc` (torus segment), `cylinder`, `plane` (half-space below), `slab`, `shell`; `scaled(shape, [sx, sy, sz])`
squashes a shape in its own frame (flat ears, fins, wings). Euler rotations are `[x, y, z]` radians.

Options that matter:

- `k` — smooth union/subtraction radius. Keep separate parts (arms beside a body, legs) farther apart than
  their `k`, or the union webs them together and skinning stretches the web.
- `color` — sRGB hex. Geometry seams (`add`/`sub` colours) are vertex colours with a crisp, sub-triangle edge.
- `paint` / `emboss` colours and masks become **shader regions**: the fragment shader evaluates the region SDF
  at the bind-pose position, so markings stay pixel-crisp at any triangle count and overlap correctly.
  - `union: [shapes]` merges same-coloured markings into one region (one consistent edge where they meet).
  - `within: shape` clips a region (straps that only cover the torso).
  - `bones: [...]` limits a region to vertices skinned to those bones (≤ 4 filtered regions per model).
  - `alpha < 1` or `fuzzy: true` gives a soft edge (blush).
- `mask` — `[trim, glow, armour, glow2]`: team trim (recoloured + patterned per team), anima glow (emissive in the
  material's glow colour), armour (recoloured by looks), animated glow (items drive it in `animate`).
- `bone` + `wk` — skin weight source and its falloff (default `0.25·k + 4 mm`; limbs use ~0.5 % of the body
  height so they never pull the torso).

Order: **all geometry first, then markings** (paints/embosses), then the uniform, then fuzzy blush. A later
`add` near an earlier marking would cut into its colour layer.

Thin features must be thicker than about one grid cell (characters: height / 58 at 中; antiques: 4–6 mm), or
the mesher misses them. `bakeModel` coarsens the grid automatically when the simplification ratio would exceed
~3× (heavy decimation cuts corners off round shapes).

## Characters

A species recipe (`species/*.ts`) returns `{ plan, sculpt, parts, face, look }`:

- `plan = bodyPlan({ H, ... })` places the 24 joints (fractions of the height). The head is ≈ 40 % of the height;
  arms hang in a gentle A-pose so they stay apart from the body.
- Build with the shared blocks of `species/body.ts` (`torso`, `legs`, `arms`, `head`, `triEar`, `chainTail`,
  `curlTail`, `nose`, `blush`), then `uniform(s, plan)` adds the harness and belt to the body and returns the rigid
  parts (anima core, buckle, back plate) attached to bones.
- `face` gives eye direction/size/iris colours, brow colour and mouth style; `layoutFace` traces the sculpt to put
  them on the surface.

Budgets at 中: body 7.2k triangles after simplification; with face, uniform parts and all four passive gear
pieces a character stays under 12k (tests check it). Generation ≈ 140–240 ms per species in Node on a desktop.

## Antiques

An item recipe (`items/*.ts`) returns `{ parts, muzzle, cell?, tris?, animate?, glow2? }`. The paw holds the
origin, +Z points to the muzzle or blade tip. Moving details are separate parts with a pivot (hippo jaw, swallow
wings, hummingbird wings, puffer body); `animate(parts, state, setGlow2)` poses them from the hand's act/charge.
How the animal holds it and what a use looks like is in `motion.ts` (`HOLD`, `readyKey`, `useTrack`).

## Draw calls and level of detail

A character is at most 4 draw calls (DESIGN §19): `assembly.ts` merges the skinned body, the rigid uniform parts,
the face lines (brows, mouths, happy eyes), the equipped gear and the クロヅメ scarf into ONE skinned geometry
(rigid pieces are skinned 100 % to one bone; extra bones under the head and the upper arms animate blinks, brows,
mouths and glider membranes), both eyes into a second, and each antique is one mesh (moving parts are bones).
Pieces keep their own paint regions through one merged region table: the `pinfo` attribute carries each
vertex's region range and flags (gear glow/dimming, unlit face lines), `rpos` its piece-local position.

Outlines are appended to the same geometry as an inverted hull (`hull.ts`, attribute `hull`); materials with
`hull: true` extrude it in the vertex shader and `uHullOn = 0` collapses it (cloak, hologram). A mesh with a hull
must use `customDepthMaterial = hullDepthMaterial()`.

Beyond `LOD_DISTANCE` (7 / 12 / 20 m at 低 / 中 / 高) a character switches to a lighter body (2.2k triangles at
中), lighter uniform parts, gear and antiques, a lighter eye, and drops the brows and the open mouth; the camera
distance comes from the body's `onBeforeRender`. Geometries are cached per species × gear set × scarf × level.

## Foes

Crowd foes (`foes/`) are rigid parts drawn with one InstancedMesh per part (`render/actors/foes.ts`):

1. A recipe (`FoeRecipe`) lists parts (`PartRecipe`: a Sculpt, a grid cell and triangle budget at 中, optional
   procedural `tubes` for thin limbs, optional `hull` / `opacity`) and an allocation-free `pose(anim, out)`.
   Thin legs, mandibles, spines and wings are `tube.ts` tubes: at crowd budgets an SDF cone collapses into
   slivers, a 6-sided tube stays round. The part's paint regions apply to its tubes too.
2. Shading is `foes/material.ts`: the toon ramp with a gloss highlight and a coloured rim; mask channels
   `HOT` (weak sacs, warning lights), `VEIN` (pulsing violet veins / cyan seams, phase-shifted per instance),
   `MATTE` (no gloss) and `EYE` (orange eye-cores, lens eyes). The renderer's instance colour is a hit flash
   when every channel is > 1, a tint otherwise.
3. Poses use `foes/rigging.ts` (`pivotMatrix`, `chain`). `anim.time` is the global clock: use a constant cadence
   per kind and scale amplitudes by `speed` (a speed-dependent frequency makes phases jump). Per-instance
   effects can only be done with part matrices (scale a glow part up, hide a part by scaling it to ~0).
4. Budgets at 中: ツブテ ≤ 1.2k triangles (crowds of 100+), other crowd foes ≤ 4k, ≤ 8 parts.

Bosses (`bosses/`) are full models posed from `FoeAnim` (state, attack, parts); props (`props/`) and projectile
looks (`shots/`) are generated once per kind and cached by the kit (`prepare` bakes the shots of the requested
antiques and foes).

- `npx vite --config .build/anima-front/vite-models.mjs` (or `.build/anima-front/models/vite-review.mjs`, the
  same without HMR) and open `http://127.0.0.1:5210/review.html` for a turntable with selectors (species, pose,
  paws, look, team, antique, quality).
- URL API: `?species=fox&pose=run&r=orca&l=bee&angle=30&look=kurozume&team=1&passives=turtle,jelly`,
  `?item=hippo&act=charge&charge=1`, `?sheet=species|views|poses|items|held|looks|faces` (+ `species`, `pose`,
  `angle`, `zoom`, `cy`, `static=1`, `quality`, `nosimp=1`).
- Foes, bosses, props, shots: `?foe=oagos&state=windup&attack=charge` (+ `st`, `speed`, `seed`, `flash`,
  `tint=shield`, `elev`, `zoom`), `?sheet=foes&state=move`, `?sheet=foe-states&foe=harigane`,
  `?sheet=crowd&foe=tsubute&n=40`, `?boss=goutetsu&parts=800,0,800,0`, `?sheet=bosses`, `?prop=lighthouse`,
  `?sheet=props`, `?shot=pillbug`, `?sheet=shots&bg=dark` (see `src/review/foes.ts`, `bosses.ts`, `props.ts`).

bosses,props,shots] [--species fox]` writes labelled contact sheets and `stats.json` (times, triangles) to
  `.build/anima-front/models/` (it reuses a server already running on 5210).
- Tests: `npx vitest run examples/games/anima-front/tests/models-`.
