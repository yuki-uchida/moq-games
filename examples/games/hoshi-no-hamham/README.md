# 星のハムハム

64×64のモダンピクセルで描く、ステージギミック最重視の2Dアクション。
スタフォー（スターフォックス）と星のカービィにインスパイアされながらも、**ギミックで答えを出す**遊びが軸です。

主人公の子ハムスター「ハム彦」が持つ行動は **歩く・ジャンプ・かじる** の3つだけ。
「かじる」は敵を攻撃するだけでなく、ステージのギミックを動かす万能の手です。

## あそびかた

| 操作 | キー |
| --- | --- |
| あるく | ← → / A D |
| ジャンプ | ↑ / W / スペース / K |
| 足場をすり抜ける | プラットフォームで ↓ |
| かじる | Z / X / J |
| 一時停止 | Esc / P |
| 音のON/OFF | M |

タッチ端末では画面下のボタンが出ます。

## ギミック

- **木** — 2回かじるとたおれる。うまく倒せば橋や落下物になる。
- **土（ひび入り）** — かじって穴をあける。縦につながる土はまとめて崩れる。
- **配管** — 穴をあけると水が噴き出し、水路やプールになる。水に入ると浮ける。
- **蜂の巣** — かじると蜂が怒り、一番近い敵に群がる。ただしハム彦も刺される。
- **眠る動物** — かじって起こすと突進し、敵を弾き飛ばす。
- **岩** — 2回かじると砕ける。果物が出ることがある。
- **スイッチ** — かじると対応する色の門がひらく。

## 全10ステージ

1. おふくろの追撃 — ママのハム代から逃げ切れ
2. 空から来た姫 — ばくろ団からハム姫を守れ
3. さらわれた姫 — 夜の森を追いかけろ
4. 奪還の作戦 — アジトに乗り込め
5. 森の逃走 — 追っ手から逃げ切れ
6. 森の巣 — 材料を8個集めて巣を作れ
7. 追っ手の反撃 — 巣を守り抜け
8. 再び、攫われて — 要塞の牢獄から脱出せよ
9. 敵の本拠地 — 暗黒城へ潜入せよ
10. 星の決戦 — 黒ハム王を倒せ

各ステージにボスがいます。10ステージクリアでエンディングです。

## 開発

```sh
npm run dev:hoshi-no-hamham      # http://127.0.0.1:5196/
npm run build:hoshi-no-hamham
npm run test:hoshi-no-hamham
npm run e2e:hoshi-no-hamham
npm run art:hoshi-no-hamham      # .build/hoshi-no-hamham-art/ に絵を書き出す
```

## テスト

- `tests/sim.test.ts` — 移動・かじり・各ギミック・目的・Determinism
- `tests/story.test.ts` — 物語の流れとセーブ
- `tests/hoshi-no-hamham-e2e.spec.ts` — 実機ブラウザでの操作確認
