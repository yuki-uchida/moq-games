# 武器と強化の分析

## 数え方

攻撃武器29種（親8・通常21）を、実際の攻撃処理で比較する。攻撃しない「蒸発済み」と、抽選先で効果が変わる「ギャンブル」は除く。親は誕生時に決まり、途中で別れもあるため、通常武器だけの数も併記する。弾数は性格による追加数を指し、武器レベルによる増加とは区別する。

時間延長は飛行・追跡時間、反復攻撃の持続、待機時間、またはSNSの連鎖数を伸ばせるものを数える。単発攻撃の表示時間や攻撃の着弾タイミングだけが変わるものは数えない。カラオケのように時間を伸ばすと波の広がり方が変わるものや、短い単発攻撃の間に敵が入ってくる場合など、状況次第の間接効果はこの集計には含めない。実際の有効性は敵との距離、命中による消滅、上限や強化量に左右される。

| 強化         | 全29種 | 通常21種 |
| ------------ | -----: | -------: |
| クールダウン |     26 |       19 |
| 範囲         |     29 |       21 |
| 弾速         |     15 |       11 |
| 弾数         |     24 |       18 |
| 効果時間     |     22 |       17 |

| 2つの強化              | 両方の恩恵（全29種） |
| ---------------------- | -------------------: |
| クールダウン・範囲     |                   26 |
| クールダウン・弾速     |                   15 |
| クールダウン・弾数     |                   23 |
| クールダウン・効果時間 |                   20 |
| 範囲・弾速             |                   15 |
| 範囲・弾数             |                   24 |
| 範囲・効果時間         |                   22 |
| 弾速・弾数             |                   15 |
| 弾速・効果時間         |                   15 |
| 弾数・効果時間         |                   19 |

| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |

## 手札を組むときの見方

- クールダウンと範囲は広く使える一方、弾速を利用する武器は約半数。弾速と時間の両方が有効な武器も15種あり、必ずしも稀ではないが、両方が飛行距離に結びつくものも多い。
- 毒親の毒空気は常時発生し、クールダウン・弾数・効果時間は無効。香水の発生間隔は固定でクールダウン補正を受けない。両武器のLv7自体には強化効果がなく、範囲は有効。香水は効果時間と弾数も利用できる。
- 友人やペットは弾速・時間・弾数がすべて役立ち、好奇心や器用と合わせやすい。ただし、速ければ常に同じ敵への命中が増えるとは限らない。
- 過保護の弾速は盾が持ち主に追いつく速さに作用し、静止時に敵を追わせるものではない。頼りない親の範囲は振り回す長さを伸ばすが、幅は変わらない。
- 好奇心は弾速と時間を一緒に伸ばす。せっかちは発動を早める代わりに時間を縮め、慎重は範囲を広げる代わりに弾を遅くし、豪快は弾数を増やす代わりにクールダウンを長くする。花壇を広く長く保つか、遠くへ運ぶか、数を増やすかで選べる。
- SNSは弾数の性格が効かず弾速も使わない。時間延長は連鎖数を増やすが、整数に丸められるため小さな強化では増えない場合がある。筋トレは即時攻撃で弾数・弾速・時間を活用できない。
- 生き物観察はクールダウン・弾数・弾速が効かず、同時に1体だけ召喚する。効果時間中はフィールドが継続する。
- 読書は好奇心で進化し、時間延長で光線の持続を伸ばせるが、弾速は使わない。ギャンブルは抽選した武器に応じて性格の恩恵が変わる。

## 新武器：ガーデニング

敵の方向に種を弧を描いて投げ、着地の0.5秒後に花壇が咲く。花壇は0.5秒ごとに周囲へダメージを与える。弾速は着地点を変えずに飛行時間を短くし、時間延長は開花後の花壇を長持ちさせる。範囲は花壇を広げ、弾数は種と花壇を増やし、クールダウンは種をまく間隔を縮める。好奇心は弾速と時間を同時に伸ばし、Lv8の進化条件にもなる。
