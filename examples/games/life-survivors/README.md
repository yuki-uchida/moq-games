# ジンセイガ・ツライデース（人生サバイバー）

人生終了後の「あなたの人生の分岐」で、本人が経験した進学・就職・結婚・家族の選択・リストラ期の実際の結果を年齢順に振り返れます。途中参加前のイベントは含まず、武器交換でも過去は変わりません。ダウン中も既存の判定どおり記録します。履歴は終幕後だけViewに追加され、隠し才能はプレイ中に公開しません。View v13の任意フィールドで、受信時は件数・イベント種別・結果文・順序・重複・未来時刻を検証します。旧版のSnapshotは受信せず、協力プレイの部屋も旧版と分離されます。

- 手札をLv4以上に育てると、小学生〜老後の姿がサッカー選手（スポーツ・筋トレ）、官僚（勉強・読書・仕事・残業）、投資家/起業家（投資・貯金・ギャンブル）などに変わります。進化済みの手札を優先し、次にレベル、同点なら手札定義順で決まります。乳幼児・寝たきりの姿は変わらず、小学生〜老後はダウン中も専用衣装を維持します。協力プレイでも参加者ごとに反映します。

赤ちゃんとして生まれ、15分（0〜80歳）の人生を生き抜くサバイバー系アクションです。最大8人の協力プレイに対応します。

人生の最後には本人の6分野の才能を六角形と倍率で公開し、各分野の武器・性格の数と、終了時の手札の名前・レベルを振り返れます。六角形は才能の倍率であり手札のレベルではありません。途中で交換した手札は含みません。

- 親はランダム（毒親・教育親・放任主義・頼りない親・過保護・モンスターペアレント・お金持ち・ヤンキー親・蒸発済み）。最初の手札と特典が決まります（蒸発済みは親の手札がなく、自立の特典があります）。放任主義の風船は真上に飛び、敵に3回当たるか時間がたつと割れ、周囲に追加ダメージとノックバックを与えます。ヤンキー親は一番近い敵に殴り込んで飛び蹴りし、肩で風を切って戻ってきます。
- 過保護親は敵を追わず、盾に接触した敵にダメージを与えて弾き飛ばします。移動速度は下がりません。盾は1枚につき1回だけ被ダメージを防ぎ、接触を含む0.5秒の無敵を与えます。防御は本人ごとに最短1.5秒間隔（防御後に最低1秒の隙）で、Lv8・勤勉・器用・好奇心を重ねても短縮できません。使用済み・再防御待ちの盾は薄く表示され、攻撃は続きます。通常の弾・ボス被弾後の無敵は、どの親でも通常の継続接触ダメージを防ぎません。毒親の基礎威力は4、毒空気は常時発生し、全武器の威力が常時+5%になる代わりに、最大精神力-10・性格／仲間／家庭の自然回復なし。食事・レベルアップでの回復は可能です。
- 才能は対人→恋愛→身体→創造→知性→資産→対人の六角形。全武器（親を含む）と通常の性格18種を分類し、仕事は知性、美容は恋愛に属します。各プレイ・各参加者で6個の独立乱数を隣と混ぜて生成するため、隣接分野は似やすく、人生ごとに異なります。倍率は0.55〜1.7、同じシードと参加順で再現します。
- 才能は武器の威力と性格の効果量に影響します。レベルと進化条件は整数のまま。器用はLv1・Lv4の弾数に加え、創造の才能に応じて威力を高めます。値はプレイ中（死神戦を含む）の公開View・協力配信から除外し、終了後に6分野すべてを表示します。手札の「手応え」は得意・ふつう・不向きの曖昧な評価で、獲得時は50%の確率で正しく、レベルが上がるたびに10ポイント上昇します（最大100%）。プレイ中も「?」から値のない六角形を確認できます。
- 手札は親の手札8種＋才能の手札22種の計30種（連鎖・ペット・衝撃波・ビーム・ブーメラン・地雷・殴り込み…と動きもさまざま）。多くの武器には特攻相手があり（例：モンスターペアレント→人間関係、お金持ち→出費、勉強→試験）、手札Lv8＋相性のよい性格で才能武器22種すべてが進化します（投資＋がめつい＝複利の魔法 など）。通常の性格は18種。攻撃は5％で会心（2倍）になります。
- ガーデニングは通常6歳から取得でき、蒸発済みの初期候補にも含まれます。種が敵に当たるか0.8秒飛ぶと花壇を作り、範囲内を0.5秒ごとに攻撃します。弾速は種の到達速度・飛距離、効果時間は着地後の花壇の寿命に作用します。好奇心で進化します。各強化と武器の対応・重なりは[武器と強化の分析](weapon-upgrade-analysis.md)を参照してください。
- 毒親の毒空気は所持中ずっと発生し、クールダウン・弾数・効果時間の補正を受けません。香水は0.35秒ごとに発生し、クールダウン補正を受けません。どちらもLv7自体の強化効果はありません。
- ギャンブルは12歳から選べ、ギャンブル以外の攻撃武器から1つを無作為に選び、12秒後の次の抽選まで繰り返し使います。抽選結果は演出に表示されます。親の攻撃も含み、未所持の武器も対象です。威力は選ばれた武器とギャンブルのレベル・進化・資産の才能で決まり、与えたダメージはギャンブルに記録されます。12歳から課金のガチャ、18歳からポーカー、23歳からパチンコ、50歳から競馬の演出に変わります。
- アウトドアは幼少期から選べ、12歳で自転車、15歳でバイク、18歳で車、23歳で飛行機に変わります。12歳未満は三輪車です。武器の性能や育成状況は変わりません。
- 敵は一般41種（うち分裂の子や召喚の手下は専用）と、人生イベントのボス12種。敵は動き方も10種（群れ・突進・射撃・鈍重・分裂・周回・瞬間移動・幽霊…）で、偏食・横暴な先輩・ボスなどは弾や突進の前触れ（「!」）を出します。2:00以降は赤く光る手ごわい個体（エリート）が混ざり、倒すと転機の宝箱かごはんを落とします。宝箱は運次第で転機が3回分になることも。
- 年齢が上がるほど選べる手札が増えます。感染症の流行・高校受験・大学受験・失恋・就職活動・確定申告・住宅ローン・親の介護・大病などの人生イベントがボスとして現れ、画面に「WARNING」と体力ゲージが出ます。
- 交際の選択で交際を始めた本人、または結婚した本人には、浮気相手の「イケメン店長」と「束縛するパートナー」が出現します。ソロ・協力ともに本人だけを追跡して接触し、本人のダウンや退出時には消えます。交際は恋愛武器の所持とは別の選択です。結婚イベントの結果は従来どおり恋愛武器のレベルに依存します。「束縛するパートナー」は12歳以降の年齢プールで出現し、周囲を回ってから本人に突進します。旧「片思いの悩み」と元の「片思い」を含む置換前の敵定義とアートは無効化して保存し、一般41種＋ボス12種を維持しています。
- 演出と効果音：レベルアップの札はレア度ごとに枠が変わり（NEW／Lv UP／進化／性格）、進化・宝箱・ステージ切り替え・イベントはバナーで見せます。効果音はすべてWeb Audioで合成します（音声ファイルなし）。Mキーまたは🔊ボタンでBGMと効果音をまとめてミュート、BGMと効果音の音量は「?」ダイアログのスライダーで別々に調整でき、設定は端末に保存されます。
- BGM：人生のステージごとに曲が変わります（乳幼児期はオルゴールの子守唄、小学生はチップチューンの行進曲、中高生はロック、青年期はジャズ、成人期・壮年期は四つ打ち、中年はブルース、老後はワルツ）。同じ曲でも幼児期・高校生・壮年期・老後は楽器が増え、寝たきりになるとオルゴールに戻ります。ボス・死神・大往生・心が折れたときは専用の曲になり、子守唄は両方のエンディングで形を変えて戻ってきます。BGMもWeb Audioでその場で合成します（`src/songs.ts` のMML譜面を `src/music.ts` が演奏）。転機を選んでいる間と精神力が尽きかけているときは、こもって聞こえます。
- 操作は移動だけ（手札は自動で攻撃）。WASD／矢印キー、スマホは画面のどこでも指を置いてスライドするとスティックが出ます。縦・横画面どちらでも遊べ、転機のカードは開いた直後の誤タップを無視します。
- 15:00に死神が迎えに来たらクリア（大往生）。全員の心が折れたら終了。倒れた仲間はそばに3秒立つと立ち直ります。

## 起動

新しい性格は、豪快（弾数増加と待ち時間増加）、大柄（最大精神力と体・当たり判定増加）、小柄（最大精神力減少と体・当たり判定縮小、移動速度増加）、せっかち（待ち時間と効果時間の短縮）、慎重（弾速低下と範囲拡大）、負けず嫌い（精神力半分以下で威力増加）です。体の大きさは性格の整数Lvで決まり、標準の0.75〜1.25倍に収まります。性格を増やしても武器の抽選機会が大きく減らないよう、通常の性格候補全体の重みを調整しています。

性格は全武器に適用される基本効果のみを持ち、武器カテゴリ同士や性格と特定武器の組み合わせによる追加効果はありません。武器の進化条件は変わりません。

SNSの連鎖回数は器用・豪快の弾数増加では増えず、効果時間の倍率で増減します。武器レベル・進化による基本連鎖数に効果時間倍率を掛け、四捨五入します。好奇心で増え、せっかちで減ります。

レベルアップの必要経験値は従来の1.25倍（整数に丸める）で、全体のレベル上昇速度を約20％抑えています。

リポジトリ直下で（初回のSDKセットアップは [sdk/README.md](../../../sdk/README.md) 参照）:

```sh
npm run dev:life-survivors   # http://127.0.0.1:5194/
npm run test:life-survivors  # ルール・バランス（ボットが15分を通しで遊ぶ）・スナップショット検証
npm run e2e:life-survivors   # ヘッドレス：ソロで死神まで、2ページでホスト／ゲスト、BGMの切り替え
npm run art:life-survivors   # ドット絵のレビュー書き出し（シート×4・GIF・モックアップ）→ .build/life-survivors-art/
E2E_PORT=5294 npm run screens:life-survivors   # 実ゲームのスクリーンショットと録画（dsf 1/2）・コマ送りストリップ → .build/life-survivors-art/{screens,playback}/
```

ドット絵はすべて `src/art/` のコードが固定シードで生成します（画像ファイルは同梱しません）。共通パレット（64色以内）・選択的アウトライン・ポーズリグで描き、ブラウザでは初回使用時に整数倍へ拡大したキャンバスをキャッシュして描画します。倒れたときは、とどめを刺した困難のタグで死に方の演出が変わります（例：人間関係→首吊り〈18歳以上のみ〉、お金→餓死）。

協力プレイはウサギ・イヤ・ラビットと同じMoQ Relay方式（`anon/life-survivors-v17/<room>`、View v13）で、ホストがゲームを計算し10Hzでスナップショットを配信します（ゲストは約15Hzで入力を送り、表示は補間します）。ゲストの入力と受信データはホスト／ゲストの双方で検証します。ステータス画面を開いている間は時間が止まり、協力プレイではホストまたは参加者のだれかが開いている間は全員の時間が止まって上部に表示されます（全員が閉じると再開。入力が1秒途絶えた停止要求は無効となり、観戦者の要求は無視されます。要求はViewの任意フィールド`paused`で共有し、部屋はv17に分離）。ソロでは転機・交際・家族の選択中も時間が止まり、協力プレイでは止まりません（選択中は移動が遅くなります）。ダウン・終幕中はカードで進行を止めません。死神移行後と勝敗確定後のカード入力は無効です。

生き物観察は通常3歳から選べる創造武器です（蒸発済みの親による出生時の手札には3歳未満でも現れます）。2秒間動かずにいると、幼児期は蟻とミミズを交互に、小学生はカブトムシ、中学生はハムスター、高校生は鳥、18歳以降は魚を召喚します。生き物はその場に残り、効果時間中ずっとフィールドを展開します。範囲内の近い敵をLv+1体まで引き寄せて減速させ、小ダメージを与えます（ボスは既存のノックバック耐性により引き寄せられません）。生き物は武器ごとに同時に1体で、移動しても効果時間までは残ります。クールダウンと弾数増加は無効、効果時間延長は有効です。好奇心で進化します。

才能武器枠が満杯なら、レベル5の倍数で通常の成長選択に加えて武器交換を予約します。通常の成長選択を消化した後、年齢・婚姻条件を満たす未所持武器から最大3候補を提示し、交換元の才能武器を選びます（親武器は交換不可、新武器はLv1）。候補選択・交換元選択のどちらでもキャンセルできます。通常候補がなければ穴埋めカードは出さず、5の倍数の交換だけを提示します。交換可能な武器がなければ交換表示も省略します。職歴の転機報酬は通常成長・交換の後に進行します。

結婚イベントの時点で恋愛武器 `w_love` がLv2以上の本人だけが結婚します。それ以外は独身の別の人生です。結婚指輪は既婚者にのみ新規取得・交換候補として現れます。子どもを迎える境界より前から参加している既婚者に、一度だけ「迎える／迎えない」のカードを提示します（ダウン中も対象）。肯定の確定時から子どもの付き添いと本人の毎秒HP1追加回復が始まり、否定では配偶者の毎秒HP2を維持します。未選択・未婚・明示拒否は別の履歴です。遅い回答は確定時刻で記録し、過去の反抗期などを再演しません。最初の肯定で共有の夜泣きの群れが一度だけ出現します。通常の子育て敵も子どものいる参加者が必要です。武器・姿では本人の回答を推測しません。境界後の参加・退出後再参加に遡及提示しません。退避した通常／交換カードと保留回数は保持され、回答後に同じ手札へ戻ります。退避手札と隠し才能はプレイ中の通信に含めません。botは回復を優先して必ず「迎える」を選びます。どちらの選択もプレイヤー自身の人生です。

親の介護は、イベント前から参加している本人の親が「蒸発済み」（`p_gone`、親はいない）以外の場合だけ対象になります。現在の武器所有とは無関係です。対象者がいなければ共有ログもボスも出ず、いれば対象者名を含む家族の試練を一度だけ表示し、全員でボスと戦えます。退出・途中参加・同一ID再参加で過去の介護イベントを再演しません。

介護と看取りは50歳で発生します。その時点で本人の親武器と発動済みの攻撃（盾・風船・突撃・弾など）を消去し、育て直しの候補にも出しません。生育環境としての親の特典（放任主義の武器枠、毒親の自然回復なし等）は残ります。老いた親が倒れ、魂と親の印が昇る6秒間の演出、本人向けバナー・ログ・読み上げ通知、終了後の人生履歴で看取りと報酬を確認できます。死亡時刻・位置・報酬はViewの任意フィールド `parentDeath` で同期し、一過性FXを取り逃しても演出と告知が復元されます。旧クライアントとはルームを分離します。

親武器がLv8なら、過保護→愛情（自然回復）、毒親→包容力（最大精神力）、モンスターペアレント→忍耐力（防御）、放任主義→勇気（威力）、教育親→勤勉、頼りない親→健康志向、お金持ち→がめつい、ヤンキー親→熱いを継承します。新4性格は通常抽選に出ず、継承後は通常どおり強化できます。既存性格と同じ効果もそれぞれ別枠として重ねられます。未所持ならLv1を追加し、性格枠6個が埋まっていても7個目として受け取れます。既に所持なら1レベル上げ、Lv5所持済みなら代わりに成長の選択を1回獲得します。その報酬や失効札の返却に通常候補がなければ食事・小遣いを選べます。Lv8未満・親武器を手放し済みなら報酬なしです。ダウン中も看取りと継承は発生しますが蘇生はしません。失効した親・最大性格のカードを除去し、選択肢が空になる場合は選択機会を返します。子どもを迎える選択の裏で保留している札も同様です。50歳の境界以降に参加した本人には過去の看取りを付与せず、その親武器を保持します。

52歳前後の固定イベント「会議、会議、また会議…」は、イベント前から参加し、28歳で会社員として就職した本人の履歴がある参加者が1人以上いる場合だけ、一度発生します。ダウン中の当事者も含み、現在の武器とは無関係です。未就職・運動・資産・創作・対人の進路、退出済み、イベント時刻以降の参加者は対象外です。共有ログに当事者名、告知に「仕事の試練」を表示し、対象外の仲間も一緒に戦えます。通常の敵プールには終わらない会議・威圧的な上司・パワハラなども出現します。

進学・職歴も本人ごとに分岐します（才能値は条件に使いません）。20歳の大学受験時に勉強 `w_study` Lv3以上なら専門課程に進学し転機1回、それ以外は実践で学ぶ進路。28歳の就職活動時に次段落の資格と順位で就職を選ぶと、専門課程の履歴があれば転機2回、なければ現場就職で1回。就職・次段落の新進路のいずれにも該当しなければ自分の道を探します。64歳のリストラ期には現在の資格から進路を再判定します。同じ仕事を続ける場合は就職履歴と仕事Lv4以上で再就職の転機2回、職歴だけなら1回です。転機は本人だけに加算され、通常のカード選択がない場合は武器交換として使えます。リストラの共有ボスは28歳に就職した履歴のある参加者がいる場合に1体だけ現れ、対象者名を表示します。大学受験・就職活動の共有ボスは従来どおり各1体で、個人別の結果は既存ログに表示します。
