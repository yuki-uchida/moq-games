# ジンセイガ・ツライデース（人生サバイバー）

人生終了後の「あなたの人生の分岐」で、本人が経験した進学・就職・結婚・家族の選択・リストラ期の実際の結果を年齢順に振り返れます。途中参加前のイベントは含まず、武器交換でも過去は変わりません。ダウン中も既存の判定どおり記録します。履歴は終幕後だけViewに追加され、隠し才能はプレイ中に公開しません。View v7の任意フィールドで、受信時は件数・イベント種別・結果文・順序・重複・未来時刻を検証します。旧版のSnapshotは受信せず、協力プレイの部屋も旧版と分離されます。

- 手札をLv4以上に育てると、小学生〜老後の姿がサッカー選手（スポーツ・筋トレ）、官僚（勉強・読書・仕事・残業）、投資家/起業家（投資・貯金・ギャンブル）に変わります。進化済みの手札を優先し、次にレベル、同点なら手札定義順で決まります。乳幼児・寝たきり・倒れた姿は従来どおり。協力プレイでも参加者ごとに反映します。

赤ちゃんとして生まれ、15分（0〜80歳）の人生を生き抜くサバイバー系アクションです。最大8人の協力プレイに対応します。

人生の最後には本人の6分野の才能を六角形と倍率で公開し、各分野の武器・性格の数と、終了時の手札の名前・レベルを振り返れます。六角形は才能の倍率であり手札のレベルではありません。途中で交換した手札は含みません。

- 親はランダム（毒親・教育親・放任主義・頼りない親・過保護・モンスターペアレント・お金持ち・ヤンキー親・蒸発済み）。最初の手札と特典が決まります（蒸発済みは親の手札がなく、自立の特典があります）。ヤンキー親は一番近い敵に殴り込んで飛び蹴りし、肩で風を切って戻ってきます。
- 才能は対人→恋愛→身体→創造→知性→資産→対人の六角形。全武器（親を含む）と性格12種を分類し、仕事は知性、美容は恋愛に属します。各プレイ・各参加者で6個の独立乱数を隣と混ぜて生成するため、隣接分野は似やすく、人生ごとに異なります。倍率は0.55〜1.7、同じシードと参加順で再現します。
- 才能は武器の威力と性格の効果量に影響します。レベルと進化条件は整数のまま。器用はLv1・Lv4の弾数に加え、創造の才能に応じて威力を高めます。値はプレイ中（死神戦を含む）の公開View・協力配信から除外し、終了後に6分野すべてを表示します。手札の「手応え」は得意・ふつう・不向きの曖昧な評価で、獲得時は50%の確率で正しく、レベルが上がるたびに10ポイント上昇します（最大100%）。プレイ中も「?」から値のない六角形を確認できます。
- 手札は親の手札8種＋才能の手札20種の計28種（連鎖・ペット・衝撃波・ビーム・ブーメラン・地雷・サイコロ・殴り込み…と動きもさまざま）。それぞれ特攻相手があり（例：モンスターペアレント→人間関係、お金持ち→出費、勉強→試験）、手札Lv8＋相性のよい性格で20種すべてが進化します（投資＋がめつい＝複利の魔法 など）。性格は12種（運がいい＝会心率と転機の札、器用＝手札の数、好奇心、空気が読める＝特攻の倍率 など）。攻撃は5％で会心（2倍）になります。
- 敵は一般41種（うち分裂の子や召喚の手下は専用）と、人生イベントのボス12種。敵は動き方も10種（群れ・突進・射撃・鈍重・分裂・周回・瞬間移動・幽霊…）で、ピーマン・先輩・ボスなどは弾や突進の前触れ（「!」）を出します。2:00以降は赤く光る手ごわい個体（エリート）が混ざり、倒すと転機の宝箱かごはんを落とします。宝箱は運次第で転機が3回分になることも。
- 年齢が上がるほど選べる手札が増えます。予防接種・高校受験・大学受験・失恋・就職活動・確定申告・住宅ローン・親の介護・大病などの人生イベントがボスとして現れ、画面に「WARNING」と体力ゲージが出ます。
- 演出と効果音：レベルアップの札はレア度ごとに枠が変わり（NEW／Lv UP／進化／性格）、進化・宝箱・ステージ切り替え・イベントはバナーで見せます。効果音はすべてWeb Audioで合成します（音声ファイルなし）。Mキーまたは🔊ボタンでBGMと効果音をまとめてミュート、BGMと効果音の音量は「?」ダイアログのスライダーで別々に調整でき、設定は端末に保存されます。
- BGM：人生のステージごとに曲が変わります（乳幼児期はオルゴールの子守唄、小学生はチップチューンの行進曲、中高生はロック、青年期はジャズ、成人期・壮年期は四つ打ち、中年はブルース、老後はワルツ）。同じ曲でも幼児期・高校生・壮年期・老後は楽器が増え、寝たきりになるとオルゴールに戻ります。ボス・死神・大往生・心が折れたときは専用の曲になり、子守唄は両方のエンディングで形を変えて戻ってきます。BGMもWeb Audioでその場で合成します（`src/songs.ts` のMML譜面を `src/music.ts` が演奏）。転機を選んでいる間と精神力が尽きかけているときは、こもって聞こえます。
- 操作は移動だけ（手札は自動で攻撃）。WASD／矢印キー、スマホは画面のどこでも指を置いてスライドするとスティックが出ます。縦・横画面どちらでも遊べ、転機のカードは開いた直後の誤タップを無視します。
- 15:00に死神が迎えに来たらクリア（大往生）。全員の心が折れたら終了。倒れた仲間はそばに3秒立つと立ち直ります。

## 起動

手札欄の「人生の相乗効果」を開くと、六角形の隣接カテゴリ6組と本人の発動状態を確認できます。知性系×資産系は資産系の威力+20%、身体系×恋愛系は恋愛系の待ち時間-10%、対人系×恋愛系は恋愛系の範囲+15%。身体系×創造系「体験が育む表現」は創造系の威力+10%、創造系×知性系「遊びからのひらめき」は知性系の待ち時間-5%、資産系×対人系「ゆとりが広げる交流」は対人系の範囲+10%。武器カテゴリで判定し、同カテゴリを複数持っても各効果は一度だけ、異なる効果は6組同時に併用できます。効果は本人の対象カテゴリの所持武器だけに反映され、仲間の手札とは合算しません。親武器・性格・家族は判定対象外です。交換・育成による効果は次の攻撃から再判定し、発射済みの通常弾は変化しません。ペットは再発動時に能力が更新され、頭数が減った分は寿命を迎えると消えます。既存の進化条件・特攻属性・家族条件・隠し才能は変わりません。

リポジトリ直下で（初回のSDKセットアップは [sdk/README.md](../../../sdk/README.md) 参照）:

```sh
npm run dev:life-survivors   # http://127.0.0.1:5194/
npm run test:life-survivors  # ルール・バランス（ボットが15分を通しで遊ぶ）・スナップショット検証
npm run e2e:life-survivors   # ヘッドレス：ソロで死神まで、2ページでホスト／ゲスト、BGMの切り替え
npm run art:life-survivors   # ドット絵のレビュー書き出し（シート×4・GIF・モックアップ）→ .build/life-survivors-art/
E2E_PORT=5294 npm run screens:life-survivors   # 実ゲームのスクリーンショットと録画（dsf 1/2）・コマ送りストリップ → .build/life-survivors-art/{screens,playback}/
```

ドット絵はすべて `src/art/` のコードが固定シードで生成します（画像ファイルは同梱しません）。共通パレット（64色以内）・選択的アウトライン・ポーズリグで描き、ブラウザでは初回使用時に整数倍へ拡大したキャンバスをキャッシュして描画します。倒れたときは、とどめを刺した困難のタグで死に方の演出が変わります（例：人間関係→首吊り〈18歳以上のみ〉、お金→餓死）。

協力プレイはウサギ・イヤ・ラビットと同じMoQ Relay方式（`anon/life-survivors-v8/<room>`、View v7）で、ホストがゲームを計算し10Hzでスナップショットを配信します（ゲストは約15Hzで入力を送り、表示は補間します）。ゲストの入力と受信データはホスト／ゲストの双方で検証します。ソロでは転機・家族の選択中は時間が止まり、協力プレイでは止まりません（選択中は移動が遅くなります）。ダウン・終幕中はカードで進行を止めません。死神移行後と勝敗確定後のカード入力は無効です。

才能武器枠が満杯なら、レベル5の倍数で通常の成長選択に加えて武器交換を予約します。通常の成長選択を消化した後、年齢・婚姻条件を満たす未所持武器から最大3候補を提示し、交換元の才能武器を選びます（親武器は交換不可、新武器はLv1）。候補選択・交換元選択のどちらでもキャンセルできます。通常候補がなければ穴埋めカードは出さず、5の倍数の交換だけを提示します。交換可能な武器がなければ交換表示も省略します。職歴の転機報酬は通常成長・交換の後に進行します。

結婚イベントの時点で恋愛武器 `w_love` がLv2以上の本人だけが結婚します。それ以外は独身の別の人生です。結婚指輪は既婚者にのみ新規取得・交換候補として現れます。子どもを迎える境界より前から参加している既婚者に、一度だけ「迎える／迎えない」のカードを提示します（ダウン中も対象）。肯定の確定時から子どもの付き添いと本人の毎秒HP1追加回復が始まり、否定では配偶者の毎秒HP2を維持します。未選択・未婚・明示拒否は別の履歴です。遅い回答は確定時刻で記録し、過去の反抗期などを再演しません。最初の肯定で共有の夜泣きの群れが一度だけ出現します。通常の子育て敵も子どものいる参加者が必要です。武器・姿では本人の回答を推測しません。境界後の参加・退出後再参加に遡及提示しません。退避した通常／交換カードと保留回数は保持され、回答後に同じ手札へ戻ります。退避手札と隠し才能はプレイ中の通信に含めません。botは回復を優先して必ず「迎える」を選びます。どちらの選択もプレイヤー自身の人生です。

親の介護は、イベント前から参加している本人の親が「蒸発済み」（`p_gone`、親はいない）以外の場合だけ対象になります。現在の武器所有とは無関係です。対象者がいなければ共有ログもボスも出ず、いれば対象者名を含む家族の試練を一度だけ表示し、全員でボスと戦えます。退出・途中参加・同一ID再参加で過去の介護イベントを再演しません。

進学・職歴も本人ごとに分岐します（才能値は条件に使いません）。20歳の大学受験時に勉強 `w_study` Lv3以上なら専門課程に進学し転機1回、それ以外は実践で学ぶ進路。28歳の就職活動時に次段落の資格と順位で就職を選ぶと、専門課程の履歴があれば転機2回、なければ現場就職で1回。就職・次段落の新進路のいずれにも該当しなければ自分の道を探します。64歳のリストラ期には現在の資格から進路を再判定します。同じ仕事を続ける場合は就職履歴と仕事Lv4以上で再就職の転機2回、職歴だけなら1回です。転機は本人だけに加算され、通常のカード選択がない場合は武器交換として使えます。リストラの共有ボスは28歳に就職した履歴のある参加者がいる場合に1体だけ現れ、対象者名を表示します。大学受験・就職活動の共有ボスは従来どおり各1体で、個人別の結果は既存ログに表示します。

28歳の候補資格は、仕事 `w_work` Lv2以上で就職、スポーツ `w_sports`・筋トレ `w_muscle` のいずれかLv4以上で運動、投資 `w_invest`・貯金 `w_savings` のいずれかLv4以上で資産、趣味 `w_hobby`・カラオケ `w_karaoke`・旅行 `w_travel`・料理 `w_cooking` のいずれかLv4以上で創作の進路です。資格のある分野だけを、外見と共通の武器ランキング（Lv4以上、進化済みはLvに8加算、同点は手札順ではなく `WEAPONS` 定義順）で比較します。就職分野には勉強・読書・仕事・残業、運動分野にはスポーツ・筋トレ、資産分野には投資・貯金・ギャンブル、創作分野には趣味・カラオケ・旅行・料理が寄与します。勉強・読書・残業だけでは就職資格、ギャンブルだけでは資産資格を得ません。仕事Lv2〜3だけで外見の順位がない場合も就職できます。才能値・攻撃ダメージは使いません。運動・資産・創作の進路は転機1回、就職は前段落どおり学歴に応じて1〜2回です。64歳には本人の現在の仕事Lv4以上、運動・資産・創作の資格武器Lv4以上から同じランキングで選び直します。28歳と別分野または進路未決定なら、64歳の履歴と転機2回を追加します。仕事の結果は、28歳に進路未決定だった履歴があれば初就職、別分野の履歴があれば仕事への転向、28歳以降の途中参加で過去が不明なら単に新たな仕事への挑戦とし、未確認の過去を断定しません。28歳の履歴は書き換えません。同分野なら継続の転機2回、現在の資格がなければ記録された過去経験で1回（進路履歴もなければ報酬なし）を保ちます。初就職を過去の雇用歴とは扱わず、それだけでは共有リストラボスは出現しません。

外見は資格条件を設けず現在の手札から選び、履歴はイベント当時の決定を保持します。そのため資格を持たない外見分野が最上位の場合や、後から武器を交換した場合は、外見と記録された進路が異なることがあります。武器外見が成立しない成人・壮年（23〜49歳）の標準姿は、水色の丸首トップスと紺のパンツ・スニーカーの私服です。年齢ごとの頭・体格は維持し、待機・歩行・被弾・ダウンでも同じ服装を使います。スーツ・ネクタイ・仕事鞄は標準姿には付けません。

小学生から老後まで、才能武器20種すべてがLv4から外見に反映されます（乳児・幼児・寝たきりの姿は変わりません）。既存の運動・就職・資産に加え、友人・SNS・ペットは対人のミント色の普段着と携帯端末、恋愛・美容・指輪・香水は恋愛のピンク色の服とスカーフ・一輪の花、趣味・カラオケ・旅行・料理は創造のオレンジ色の服と作業エプロン・スケッチノートになります。服や小物は関心分野の表現であり、職業・婚姻状態を断定しません。本人の所持武器だけをLvと進化で比較し（Lv8と対応人格Lv1以上で8加算）、同点は `WEAPONS` 定義順です。親武器・人格だけや他の参加者の手札では変化せず、武器交換後は現在の手札で選び直します。年齢別の体格と既存の待機・歩行・被弾ポーズ、再生タイミングは維持します。対人・恋愛の外見は表示専用で、進路や結婚の資格には使いません。創作は本人の武器で28歳の進路候補にもなりますが、外見そのものを資格判定には使いません。

各判定は一度だけで、交換しても進学・就職・新進路の履歴は残りますが、その時点の分野別レベル条件は交換後の手札で判定します。ダウン中も確定・報酬を保留し、復活後に選択（自動復活はしません）。途中参加は参加時刻以前の判定を飛ばし、将来の現場就職や新進路は可能です。退出で履歴と未消化報酬を破棄し、同一IDで再参加しても継承しません。8人でも各本人のみ判定します。履歴はプレイ中はホスト内部に保持し、終幕後にViewへ追加します。結果画面には実際に確定した進路と64歳の分岐結果を本人別に表示します。

配偶者は長い黒髪とコーラル色のワンピースの女性、子どもは既存の小学生アートで、どちらも本人より小さく（0.75倍）本人の向きと反対側の少し後ろに付き添います。移動中は少し遅れて後を追いますが離れすぎず、本人が向きを変えると反対側の後方へ回り込みます。名前ラベルや足元の輪は付けず、本人のHPが減っている間だけ小さな回復マークがときどき浮かびます。配偶者は本人のHPを毎秒2、子どもは毎秒1追加回復します（最大HPまで）。通常の武器枠・抽選は消費せず、一人につき各一人まで。ダウン・退出・終幕中は支援を停止します。攻撃や他人への回復は行いません。旧版とは部屋を分離しています。
