# Life Survivors（人生サバイバー）

赤ちゃんとして生まれ、30分（0〜80歳）の人生を生き抜くサバイバー系アクションです。最大8人の協力プレイに対応します。

- 親はランダム（毒親・教育親・放任主義・頼りない親・過保護・モンスターペアレント・お金持ち・蒸発済み）。最初の手札と特典が決まります。
- 才能（友人・スポーツ・勉強・恋愛・美容・娯楽・仕事・投資）は隠れています。同じ手札でも威力が大きく変わり、最後の「人生のふりかえり」で明かされます。手札を得たときの「手応え」は4回に3回だけ正しい。
- 手札にはそれぞれ特攻相手があります（例：モンスターペアレント→人間関係、お金持ち→出費、勉強→試験）。手札Lv8＋相性のよい性格で進化します（投資＋がめつい＝複利の魔法 など）。
- 仕事は16歳から、投資は20歳からなど、年齢で選べる手札が増えます。高校受験・大学受験・就職活動・住宅ローン・大病などの人生イベントがボスとして現れます。
- 30:00に死神が迎えに来たらクリア（大往生）。全員の心が折れたら終了。倒れた仲間はそばに3秒立つと立ち直ります。

## 起動

リポジトリ直下で（初回のSDKセットアップは [sdk/README.md](../../../sdk/README.md) 参照）:

```sh
npm run dev:life-survivors   # http://127.0.0.1:5194/
npm run test:life-survivors  # ルール・バランス（ボットが30分を通しで遊ぶ）・スナップショット検証
npm run e2e:life-survivors   # ヘッドレス：ソロで死神まで、2ページでホスト／ゲスト
```

協力プレイはウサギ・イヤ・ラビットと同じMoQ Relay方式（`anon/life-survivors-v1/<room>`）で、ホストがゲームを計算し10Hzでスナップショットを配信します（ゲストは約15Hzで入力を送り、表示は補間します）。ゲストの入力と受信データはホスト／ゲストの双方で検証します。ソロでは転機（レベルアップ）の選択中は時間が止まり、協力プレイでは止まりません（選択中は移動が遅くなります）。
