# サブエージェント起動ルール

## モデル

基本は次のどちらか。親の model / effort は継承させず、毎回明示する。

| モデル          | 起動方法                                                                                                                                                                                                          |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Claude Opus 5.5 | Agent ツール: `model: "opus"`, `effort: <レベル>`（`run_in_background: false`）<br>T3 `delegate_task`: `target: { providerInstanceId: "claudeAgent", model: "claude-opus-5-5", options: { effort: "<レベル>" } }` |
| GPT-6.1 Terra   | T3 `delegate_task`: `target: { providerInstanceId: "codex", model: "gpt-6.1-terra", options: { reasoningEffort: "<レベル>" } }`                                                                                   |

- 使い分け: Claude 系の作業・同一会話文脈が必要なら Opus 5.5。別視点のレビュー・独立した検証・並列で別プロバイダに任せたいときは GPT-6.1 Terra。
- ユーザーがモデル・設定を名指しした場合はそれに従う（このスキルより優先）。
- `delegate_task` の前に、スレッドで未実施なら `orchestrator_capabilities` を一度呼ぶ。指定モデルが使えなければその旨を伝え、勝手に別モデルへ切り替えない。

## 推論レベル

自分でタスク難易度を判断して設定する。**迷ったら一段低いレベルにする。**

| レベル     | 目安                                                                                |
| ---------- | ----------------------------------------------------------------------------------- |
| low        | 検索・ファイル列挙・定型的な機械的変更・単純な確認                                  |
| medium     | 通常の実装・小〜中規模の修正・一般的なレビュー                                      |
| high       | 複数ファイルにまたがる設計判断、原因不明のバグ調査、厳密なレビュー                  |
| xhigh 以上 | 高難度のアルゴリズム・アーキテクチャ、high で失敗した再試行。原則ユーザー指示時のみ |

例外（ユーザー指定・迷っても下げない）:

- 3D モデリング（モデル作成・リギング・Blender でのメッシュ/アニメーション制作など）は **xhigh（Very High）** 固定。

## 起動時の報告

起動時に一行で「モデル / 推論レベル / 理由」をユーザーに示す。例: `Opus 5.5 / medium — 通常の実装修正のため`
