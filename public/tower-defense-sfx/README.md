# Generated game sound effects

These 22 original WAV files were generated on 2026-10-04 with Stable Audio 3 Small-SFX, official optimized MLX backend (`sm-sfx`, `same-s`), then trimmed, faded and level-adjusted for this non-commercial game demo. The published bytes are unchanged from the preserved processed originals: 44.1 kHz, 16-bit PCM, stereo. The runtime catalog records SHA-256 and duration for its 21 selected sounds; `healer_attack.wav` is retained but is not currently selected because healing uses a separate event.

The game limits simultaneous voices, supports mute and volume controls, verifies loaded hashes, and permits bounded retries without replaying old combat events.
