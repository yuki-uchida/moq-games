# Title portraits

These transparent 1024×1024 PNGs are title-only renders of the existing soldier,
archer, and mage idle models used by the game's EXTRA viewer. They were captured
from that viewer in headless Chrome with a transparent background, the default
camera, and two zoom steps. The original 2D portraits and runtime GLBs remain
unchanged. Existing model provenance is recorded in
`examples/games/tower_diffence_with_jev/src/rendering/models/asset-provenance.json`.
