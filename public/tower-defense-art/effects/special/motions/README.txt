Ally ultimate motions v1

Runtime: ten *.ultimate.json files are THREE.AnimationClip.parse-compatible, normal (non-additive) clips. Play once with loop false; stop the base idle/walk/attack action while playing, then return to the idle state. Sample seconds directly; do not stretch the timeline unless gameplay/VFX timing is stretched equally. Full duration, charge/impact/recovery cues are in manifest.json. Runner has three distinct impacts. Most tracks sample at 60fps; Runner uses 240fps to keep the independent spear grip stable during the rapid thrusts.

Bind to each role's ORIGINAL IDLE MODEL scene, preserving the skeleton, hierarchy, material adapters, and external parent placement/facing. No mesh, materials, bone parenting, bind matrices, scales or outer unit placement are changed. All bone positions are held constant at their exact original idle-frame-zero local values. Internal rig root position is also an idle baseline constant; there is no root displacement or outer unit movement. Soldier uses 60fps intermediate root quaternion keys to complete a full turn without a shortest-path cancellation. GLTFLoader strips dots from node names; supplied track names already match the loaded Three scene.

Weapons: eight roles contain independent rigid weapon controls. Their position/quaternion tracks are mandatory, including Archer_Bow_Grip_Control, Ranger_Bow_Grip_Control, Spear_Rigid_Control, Staff_Rigid_Control, Cannon_Rigid_Control and the two Paladin controls. They follow the original idle hand-to-weapon relative transform. Do not filter tracks to bones only. Do not also run an old attack clip or an adapter that overwrites these controls. Existing DQ/material adapters may continue.

Design: soldier rotational cut; archer upward draw/release; runner triple spear thrust; tank braced shield slam; mage overhead fire charge and throw; healer gather/open arms; frost crossed-arms field expansion; ranger low plant and pull; cannon brace/load and sharp recoil; paladin bow/raise sword into light. All motions have a charge, sharp release and eased recovery to their original idle quaternion pose. These are authored new joint curves, not reused attack clips.

Verification: three-validation.json was generated using actual THREE.GLTFLoader and AnimationMixer, all tracks resolving, 60Hz finite positive-determinant bone matrices, and ending idle quaternion deviation under 0.001 rad, position error below 1.1e-8 model units. Independent weapon-to-hand relative transforms were additionally measured at 120Hz: all position drift below 0.0022 model units; exact key samples are below 1e-6 matrix-element error. Browser-specific GPU/DQ runtime validation and gameplay/VFX timing must still be checked in the game. Blender Workbench images check geometry and weapon attachment; they are not the game's GPU/material rendering.

Source: original model paths and SHA256 hashes in manifest.json. Original source GLBs were read-only. *.validation.glb are separate QA-only copies with replaced animation arrays, not runtime assets. The .blend files preserve each source's imported rig and contain the dedicated ultimate action, camera and QA scene. Blender 4.3.2.

Regenerate: Python 3 + numpy + scipy. Set DQ_MODEL_ROOT to the repository public/tower-defense-art/models path, then run generate.py. ULTIMATE_OUTPUT_DIR optionally changes output. render.py should be placed in that output folder and run with Blender --background --python render.py. verify-three.mjs requires the repository's Three dependency ; set DQ_MODEL_ROOT to the source models directory and ULTIMATE_OUTPUT_DIR if needed.
