# Artwork and optional packs

The public distribution includes the existing original 2D runtime roster, effects and commander artwork. The retained upstream art README identifies these as original assets created for this project, not copied Tiny Swords assets. Local production records identify built-in OpenAI image generation and offline assembly of original raster parts, including the Leaf Squire, Mage, Healer, Frost, Slime, Bat, Brute and Wraith records. Other roster records describe original generated character artwork and preserved derivatives. These are AI-generated assets, not represented as wholly human-drawn artwork.

Publication basis: the project owner's explicit publication instruction, the original-source records, and OpenAI's output ownership terms (https://openai.com/policies/terms-of-use/, Content section). Those terms assign output rights as between the customer and OpenAI to the extent permitted by law; they do not guarantee copyright or third-party non-infringement. Pixel Frog's Tiny Swords was a visual reference, not an included third-party asset pack. Existing upstream license notices are retained; no separate third-party Tiny Swords license is claimed for these original derivatives.

The full-roster distribution includes the approved Slime rendered frames described below and 30 optimized runtime GLBs covering all 20 unit roles. Browser acceptance covers the normal-game real-mesh path. Large source models are excluded from the public tree. The owner confirmed Meshy Pro generation and publication rights; Meshy terms distinguish paid-output ownership from the free-plan CC BY 4.0 license (https://www.meshy.ai/terms-of-use). Original files remain preserved locally and unchanged.

The owner approved publication of the 22 Stable Audio-generated WAV outputs in `public/tower-defense-sfx/`. These unchanged processed originals were made with Stable Audio 3 Small-SFX / optimized MLX for the non-commercial demo. The existing runtime selects 21 sounds; the retained healer attack recording is currently unselected. Model weights, encoder, inference runtime and private generation records are excluded. See the [sound asset notes](public/tower-defense-sfx/README.md) for pinned source and model-term references; no blanket commercial-use license is claimed.

The normal game uses the accepted real-mesh path for all 20 unit roles; see [the verification commands in README](README.md). It does not fall back to sprites or replacement characters when a model fails. Combat balance is unchanged. The original 2D source artwork, excluded optional packs and unadopted candidates remain preserved. Battle music is approved separately below; the approved Stable Audio SFX pack is included.

## Preserved Slime rendered frames

`public/tower-defense-viewer/sheets/slime/` contains the approved melted-base Slime 3D-rendered frame derivatives: idle, walk, attack and death in eight directions (32 clips, 1,632 frames). These PNG/JSON bytes are copied unchanged from the `slime-melt-2d-runtime-candidate.zip` delivery, SHA-256 `c2a822364a6fcc5bd9d7fad859412f2f28b7ae9d2fc08e0c15a794656f6fdd77`. Source-art ownership and Meshy Pro generation terms were reconciled before inclusion. These previously approved rendered frames remain preserved, but neither EXTRA nor gameplay loads them. The read-only EXTRA viewer uses the same real-time GLBs and authored-animation adapters as gameplay. No source `.blend`, model `.glb`, credentials or production/debug-service data are included in this viewer asset directory. Death remains non-looping at 1,200 ms.

## Approved battle music

## Full runtime roster

`public/tower-defense-art/models/runtime-manifest.json` records every source/derivative SHA-256, byte count and optimization configuration. The existing 30 optimized GLBs total 186,209,172 bytes. The three new source-identical Blender GLBs add 34,958,100 bytes; the staged runtime manifest now records 33 GLBs totaling 221,167,272 bytes. The three additions were reviewed on arm64 Chrome with ANGLE Metal: 23-role board placement, all 71 available EXTRA clips, eight-direction samples, recorded motion playback and saved encounters. Authored material, dual-quaternion skinning and additional-weight adapters are included with the rendering source. Runner was exported from its current spear-bearing authored source, with visual timing mapped to existing game combat timing. See [README](README.md) for lazy-loading budgets and browser checks. Dedicated motion coverage includes Healer healing, Dragon breath and Slime death. Paladin healing holds a neutral pose; other roles retain their final pose for the short corpse fade. Runner's authored 640/320 ms attack/contact is sampled at 4/3 speed to preserve the game's existing 480/240 ms timing.

## Approved compact meadow map

`public/tower-defense-map/approved-meadow.png` is the original, unchanged OpenAI-generated landscape that the owner selected on 2026-10-12 for the tower-defense map replacement. It is 1478×1064 pixels, 3,053,262 bytes, SHA-256 `a6277807b1dc416815ba588766acda5f55b120c0e566e1a68114838e3abeabe7`. The source is scaled to the 1280×920 battlefield. `ApprovedMazeLayout.ts` traces its single continuous road with rounded corners; a regression samples every two source pixels along the exposed-road centerline and checks alignment against the unchanged PNG. Its purple cave, castle, and decorative pads are background art; units remain runtime GLB meshes and pads do not constrain placement. The same approved grass map is used for each existing field choice. No generated model, private reference asset, or debug sprite is added by this replacement.

## Three new original enemies

Crystal Sentinel, Amber Kobold Lancer and Clockwork Patchling use the owner-provided concept images and Meshy Pro outputs, with cloud Blender topology repair, skinning and authored animation derivatives. Their complete final GLBs are copied without additional geometry/texture optimization. Final/source/concept hashes, clip durations and normalization are recorded in `examples/games/tower_diffence_with_jev/src/rendering/models/asset-provenance.json`; `public/tower-defense-art/models/runtime-manifest.json` identifies the exact selected final bytes. UI portraits are unchanged concept PNGs, not gameplay sprites. Private account/file identifiers, source archives, Blender projects and private access URLs are excluded from public files. Originals remain preserved separately.

Source provenance was supplied by the owner; this integration does not establish an independent license grant or relabel the assets as public domain. The publishing owner must retain the applicable source rights. Blender reimport and Three.js CPU contracts are checked. Mac game/EXTRA rendering, lighting and materials were reviewed with the final bytes. Original 2D source-to-motion comparison remains outside this runtime integration review because the separate raw-source archive was not materialized. All three have actual idle/walk/attack clips. Their deaths deliberately use the existing held-pose/fade policy rather than a fabricated animation.
