# Artwork and optional packs

The public distribution includes the existing original 2D runtime roster, effects and commander artwork. The retained upstream art README identifies these as original assets created for this project, not copied Tiny Swords assets. Local production records identify built-in OpenAI image generation and offline assembly of original raster parts, including the Leaf Squire, Mage, Healer, Frost, Slime, Bat, Brute and Wraith records. Other roster records describe original generated character artwork and preserved derivatives. These are AI-generated assets, not represented as wholly human-drawn artwork.

Publication basis: the project owner's explicit publication instruction, the original-source records, and OpenAI's output ownership terms (https://openai.com/policies/terms-of-use/, Content section). Those terms assign output rights as between the customer and OpenAI to the extent permitted by law; they do not guarantee copyright or third-party non-infringement. Pixel Frog's Tiny Swords was a visual reference, not an included third-party asset pack. Existing upstream license notices are retained; no separate third-party Tiny Swords license is claimed for these original derivatives.

This selected distribution includes the approved Slime rendered frames described below and one Slime GLB for the dedicated model-review page. The other real-3D runtime packs and source models are excluded from this selection while their optimization and browser acceptance work continues. The owner confirmed Meshy Pro generation and publication rights; Meshy terms distinguish paid-output ownership from the free-plan CC BY 4.0 license (https://www.meshy.ai/terms-of-use). Original files remain preserved locally and unchanged.

The owner approved publication of the 22 Stable Audio-generated WAV outputs in `public/tower-defense-sfx/`. These unchanged processed originals were made with Stable Audio 3 Small-SFX / optimized MLX for the non-commercial demo. The existing runtime selects 21 sounds; the retained healer attack recording is currently unselected. Model weights, encoder, inference runtime and private generation records are excluded. See the [sound asset notes](public/tower-defense-sfx/README.md) for pinned source and model-term references; no blanket commercial-use license is claimed.

The clean public game uses its existing 2D default and procedural battlefield fallback. Optional 3D controls require the authorized local packs; without them, their existing load-error/rollback behavior applies. Included effects start after user interaction and support mute, volume and bounded load retries. No procedural character replacement or different combat balance is introduced. Excluded optional packs and unadopted candidates remain preserved locally.

## EXTRA: viewer-only rendered frames

`public/tower-defense-viewer/sheets/slime/` contains the approved melted-base Slime 3D-rendered frame derivatives: idle, walk, attack and death in eight directions (32 clips, 1,632 frames). These PNG/JSON bytes are copied unchanged from the `slime-melt-2d-runtime-candidate.zip` delivery, SHA-256 `c2a822364a6fcc5bd9d7fad859412f2f28b7ae9d2fc08e0c15a794656f6fdd77`. Source-art ownership and Meshy Pro generation terms were reconciled before inclusion. The rendered frames are available only through the read-only EXTRA viewer; they are not substituted for real-time game models. No source `.blend`, model `.glb`, credentials or production/debug-service data are included in this viewer asset directory. Death remains non-looping at 1,200 ms.


## Slime: real-model review

`public/tower-defense-art/models/slime/animated.glb` is the approved Slime model used by `examples/games/tower_diffence_with_jev/model-review.html`. It contains nine meshes and the authored idle, walk, attack and death clips. The included publication derivative has SHA-256 `2216dffa79924084886c6112a082ec0cf8b5f6fb2f1f649f0423a935987e1a66`. Only private source-library identifiers were removed from JSON metadata; geometry and animation binary chunks are byte-identical to the original. This review page renders actual geometry. It does not enable the full real-3D roster in the normal game or establish acceptance of the excluded models.
